## 像素表面与招牌

- 重绘 512×512 的墙／屋顶／钢架／木板图集和 512×128 位图字牌；字牌内容为 `INSURANCE CO.`、`CARGO CRANE`。
- 图集采用有限色阶和阶梯色块，不复用生成模型的法线、高光和杂乱烘焙细节。
- 图集面目标密度为 32 texels／模型单位；字牌单独映射。没有宣称所有 UV 端点均已整数像素吸附。
- 所有分件使用同一个活动 UV 层 `PixelUV`。旧样板的字牌 UV 层名不同，运行分组合并后首通道塌缩；本版在合并前和 GLB 导出后均检查了两个字区的 UV 跨度。
- R2.1 将保险招牌整体前移并加墙面支架，修正屋檐遮挡字区的问题；同时补山墙与屋面的接缝，修正三个实心黑色外框遮住彩色箱体／驾驶舱侧面的问题。
- 源模型平面法线，无平滑高光或法线贴图。Godot 评审器逐表面复制材质，设为 nearest、粗糙度 1、金属度／镜面 0；PNG 无损、无 mipmap，关闭自动 LOD。

这些是实现措施，不是像素插画风或 HD-2D 美术验收结论。字牌的实际屏幕可读性、纹理密度、配色和轮廓仍需目视评审。
