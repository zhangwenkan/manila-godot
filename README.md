# 马尼拉港

在 Godot 4.6 中打开本目录的 `project.godot`，按 **F5** 运行。

也可以双击根目录的 `open_godot.bat`，它会打开根工程并选中港口主场景。编辑器窗口标题应显示 `manila-godot`。如果旧的 `Tropical Water Study` 编辑器仍开着，先关闭它；旧窗口会继续按子工程路径重写贴图导入记录。

唯一主场景为 `demo/tropical_harbor_3d/fleet_harbor.tscn`，水、船、正常栈桥、破桥和交互都在此入口。原来的独立水体工程已并入根工程。历史角色和 UI 文件保留为开发资料，不是当前入口。

- 点击船只或顶部货物按钮查看船只，点击空位派遣船员。
- **栈桥 / P** 查看栈桥；**总览 / V** 返回港口；**空格** 暂停；**Esc** 退出。
- `python demo/tropical_harbor_3d/tools/capture_art.py`：从同一主场景生成限时美术截图。
- `python demo/tropical_harbor_3d/tools/capture_art.py water`：从同一入口检查水体总览、浅水、桥桩、船边、低角度，并保存覆盖一个岸浪周期的 48 帧动画素材。`water-diagnose` 可分别关闭高光、天空反射、阴影和海床定位问题。
- `python demo/tropical_harbor_3d/tools/capture_fleet.py`：从同一主场景检查已有交互并截图。
- `python demo/tropical_harbor_3d/tools/capture_art.py reference-stills`：在同一主场景临时摆放现有船桥，以近似参考视角拍摄浅滩、岸桥、外侧桥、深水桥和开阔海面；不保存摆放。`reference-idle` / `reference-sail` 记录真实漂浮与航行动画；`reference-detail` 分离水面投影、海底投影及 SSAO，可追加 `2560x1440` 检查原生分辨率。

运行工具可用 `GODOT_EXE` 指定引擎路径。截图和日志保存在 `demo/tropical_harbor_3d/captures`。美术截图仍需人工验收。

当前船和正常栈桥的木纹及材质已获用户认可。破桥与其他船只延后到场景制作时处理。美术参考仍以《I Just Wanted to Fish》的实际画面为准。

2026-11-05 对照后的调整：[前后截图与动画](demo/tropical_harbor_3d/captures/water_adjustment_20261105/index.html)。总览改为按当前船只与码头取景，俯视角约 56°；减少水面的实心投影，保留海底投影。浅水与海床偏青绿，焦散变淡且分布更疏密，细碎波光适配主要取景；固定白天侧光强化木板明暗。船只与水面同步加入缓慢长波，固定 8 秒采样的漂浮上下变化从约 1.2 cm 提升至 4.9 cm；转向限速 75°/秒并随朝向减速，尾流变淡、断续。模型、正式船桥摆位和唯一场景入口保持原样。

此轮验证：194 项交互检查通过，暂停、独立尾流及尾流清除检查通过；最终 7 张静态、80 帧漂浮、80 帧航行及 11 张低角度诊断采集正常退出，日志无错误或警告。根工程编辑器已实际启动主场景。1600×900、5 秒性能采样总览平均 29.4 ms / p95 33.8 ms，近景平均 27.6 ms / p95 33.5 ms；比此前记录偏慢，原因尚未隔离，不视为性能达标。桥的相对宽度、结构材质和镜面反射仍待后续调整。

2026-11-06 水体优化收尾：[七视角与倒影开关对照](demo/tropical_harbor_3d/captures/water_optimization_20261105/index.html)。海底投影随水深减淡，近岸接触明暗保留；启用低分辨率船桥倒影，适配正交、透视与窗口比例变化。独立复制反射天空资源，修复暂停时主画面亮度交替。环境遮蔽采样由 Medium 降为 Very Low（前后均已开启半分辨率），海床停止向太阳阴影级联投射，继续接收船桥阴影。

最终 206 项交互与反射对齐检查通过；暂停稳定、独立尾流和清除恢复检查通过。7 张最终静态图、12 张倒影诊断图与性能采集日志无引擎错误或警告。1600×900、同进程交替各两轮、每轮预热 1 秒并采样 3 秒、关闭垂直同步的对照中，两轮平均帧耗时为 23.63 → 17.30 ms，降低约 26.8%；这是本机短时结果。独立回归 5 秒采样的总览平均 14.54 ms / p95 16.16 ms，近景平均 12.74 ms / p95 14.09 ms。系统负载有波动，不将不同批次直接相减。
