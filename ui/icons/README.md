# 个人栏货物图标

此目录保存用户提供的原图：`silk.png`（丝绸）、`nutmeg.png`（肉豆蔻）、`jade.png`（玉石）、`ginseng.png`（人参）和 `backdrop.png`（草地底座）。

`hud/` 中的作物和底座是游戏使用的透明裁切副本：移除外围低透明度的灰色残留，以及底座四角残留的棋盘格；保留原图色彩和分辨率。原图不会被覆盖。

替换原图后，在项目根目录重新生成显示副本：

```powershell
python tools/build_hud_cargo.py
```

个人栏使用最近邻过滤，将四种货物按各自长宽比缩放，放在同样大小的底座顶面上。货物比底座小，落点位于草地内部，前方保留草地，再露出土层的厚度。显示比例和落点在 `ui/personal_bar.gd` 中设置。

金币分别使用用户提供的两张 PNG：四种货物金额旁使用 `hud/coin.png`（24 × 24 显示区域），左侧角色余额旁使用 `hud/coin_total.png`（32 × 32 显示区域）。两者都保持原图比例和颜色，使用最近邻过滤。

参考图上的金额不作为游戏数据，界面数值由 `set_stock_values()` 传入。
