## R01：目标、人数与开局

玩家通过派人参与航运、投资港口和修船厂、海盗活动以及持有股票积累财富。游戏进行若干次航程，直到一种货物的行情达到 30；最终财富最高者获胜。

| 内容 | 原版设置 |
| --- | --- |
| 玩家人数 | 3–5 人 |
| 初始现金 | 每人 30 比索 |
| 初始股票 | 股票洗混，每人随机获得 2 张，自行查看，不向其他玩家展示 |
| 股票总量 | 四种货物各 5 张，共 20 张；未发出的按货物分类，作为可购买的库存 |
| 每人小人 | 4–5 人局：3 个；3 人局：4 个 |
| 船只与航线 | 3 艘船，3 条独立航线 |
| 货物与骰子 | 4 种货物及对应骰子；每航程选其中 3 种装船 |
| 初始行情 | 四种货物都从 0 开始 |

本文将原文的 accomplice 统一称为“小人”，海上运输单位称为“船”，一次从竞拍到结算的循环称为“航程”。“派遣轮”与“航行次数”分开计数，避免三人局混淆。

**本项目用角色替代玩家颜色身份。角色代表玩家，不代表船的所有者。三艘船都可以容纳不同玩家的小人。**

## R02：数值速查

### 货物与船位

| 货物 | 英文 | 原版辅助色 | 座位数 | 座位费用，由便宜到贵 | 成功运抵的整船分红 |
| --- | --- | --- | --- | --- | --- |
| 人参 | Ginseng | 黄色 | 3 | 1 / 2 / 3 | 18 |
| 肉豆蔻 | Nutmeg | 棕色 | 3 | 2 / 3 / 4 | 24 |
| 丝绸 | Silk | 蓝色 | 3 | 3 / 4 / 5 | 30 |
| 玉石 | Jade | 绿色 | 4 | 3 / 4 / 5 / 5 | 36 |

上述分红是供船上小人分配的**整船总额**，不是每名小人的收入，也不是股票行情。货物决定座位容量和费用，不宜把所有船永久做成相同的三座船。

数值对照：[四货物装载图](https://www.ultraboardgames.com/manila/gfx/game5.jpg)、[船位图](https://www.ultraboardgames.com/manila/gfx/game10.jpg)。

### 岗位

| 岗位 | 放置费用 | 成功时收入或效果 |
| --- | --- | --- |
| 港口 A / B / C | 4 / 3 / 2 | 对应泊位有船时，领取 6 / 8 / 15 |
| 修船厂 A / B / C | 4 / 3 / 2 | 对应泊位有受损船时，领取 6 / 8 / 15 |
| 海盗船长 / 海盗次席 | 各 5 | 第二次航行后可能登船；第三次航行后可能劫掠 |
| 小引航员 | 2 | 第三次航行前，可把一艘船移动 1 格，方向自选 |
| 大引航员 | 5 | 第三次航行前，可把一艘船移动最多 2 格，或两艘船各移动 1 格 |
| 保险 | 0 | 立即领取 10；本航程有船进入修船厂时承担相应赔付 |

每个岗位位置只能放一个小人。同一玩家可以占多个不同位置，包括同时占海盗两席。

港口与修船厂的 A/B/C 是按到达数量依次使用的泊位，不绑定某种货物。例如两艘到港、一艘受损，则港口 A、B 和修船厂 A 有船；其余泊位没有收益。

数值对照：[港口](https://www.ultraboardgames.com/manila/gfx/game11.jpg)、[修船厂](https://www.ultraboardgames.com/manila/gfx/game12.jpg)、[海盗](https://www.ultraboardgames.com/manila/gfx/game13.jpg)、[引航员](https://www.ultraboardgames.com/manila/gfx/game14.jpg)、[保险](https://www.ultraboardgames.com/manila/gfx/game15.jpg)。

### 行情与贷款

| 项目 | 数值 |
| --- | --- |
| 行情刻度 | **0 → 5 → 10 → 20 → 30** |
| 港务长买一张股票 | 当前行情，最低 5 |
| 抵押一张未抵押股票 | 获得 12 |
| 赎回一张抵押股票 | 支付 15 |
| 终局每笔未清贷款 | 财富中扣除 15 |

“行情上涨一格”不等于“每次加 5”。行情刻度见[原版行情图](https://www.ultraboardgames.com/manila/gfx/game2.jpg)。

<a id="r03"></a>
## R03：一次航程的完整顺序

1. 竞拍港务长。
2. 港务长可购买一张股票，然后选择三种货物并配置三船起点。
3. 交替派人和航行，期间处理海盗登船与引航员。
4. 第三次航行后处理海盗劫掠，确定所有船进入港口还是修船厂。
5. 分配收益，完成保险赔付。
6. 到港货物行情上涨；达到终局条件则结算整局，否则收回小人并开始下一航程。

第三步的详细顺序如下。派遣一轮是每位仍可派人的玩家依次获得一次派遣机会，不是某一个玩家放完所有小人。

| 顺序 | 4–5 人局 | 3 人局 |
| --- | --- | --- |
| 第一次航行前 | 派遣第 1 轮 | 派遣第 1 轮 → 派遣第 2 轮 |
| 第一次航行 | 投骰并移动 | 投骰并移动 |
| 第二次航行前 | 派遣第 2 轮 | 派遣第 3 轮 |
| 第二次航行 | 投骰并移动 → 检查海盗登船 | 同左 |
| 第三次航行前 | 派遣第 3 轮 → 小引航员 → 大引航员 | 派遣第 4 轮 → 小引航员 → 大引航员 |
| 第三次航行 | 投骰并移动 → 检查海盗劫掠 → 三船归位 | 同左 |

不存在的岗位或没有合法目标的事件直接略过。借款是可插入的资金操作，不是增加一轮派遣或重开当前阶段。

<a id="r04"></a>
## R04：港务长竞拍与准备

### 竞拍港务长

- 第一航程由年龄最大的玩家先出价或放弃。后续航程由上一任港务长开始。
- 顺时针轮流出价，首次报价至少 1；之后必须超过当前最高报价。
- 放弃后，本次竞拍不能重新加入。
- 仅剩一名未退出的出价者时，其获胜并向银行支付自己的最后报价；未得标者不支付报价。
- 出价不得超过自己能支付的金额，可以计入未抵押股票能够提供的贷款。
- 后续航程无人出价时，上一任港务长继续任职。首航全部放弃的情况，所查文字没有清楚解释，见 [R12](#r12)。

### 港务长按顺序做三件事

1. **可买一张股票，也可不买。** 只能从剩余库存中选购，价格为当前行情，最低 5。购买后放入自己的持股。
2. **从四种货物中选三种。** 每艘船装一种，三船不重复；未选货物本航程不出航。
3. **配置三船起点。** 每船使用独立航线，起点可选 0–5，三船起点之和必须恰好为 9，例如 5/4/0 或 3/3/3。

港务长控制本航程的准备与投骰，不会因此拥有三艘船，也不会自动取得货物收益。

<a id="r05"></a>
## R05：派人

每轮由港务长开始，按顺时针顺序，每人放置一个可用小人到一个合法空位，支付该位置的费用。保险和贫困派遣另有规定。

- 船上、港口、修船厂、海盗、引航员、保险都是可派遣的方向。
- 选定一艘船后，应使用该船**最便宜的空座位**。不能任意跳过更便宜的空座。
- 同船可以有多个玩家；同一个玩家也可以在后续轮次继续向同船派人。
- 已到港的船不再接收新小人；已占用的位置不能再放人。
- 可以放弃派遣，但含义是**本航程不再派人**，不是只跳过当前这一次。
- 没钱不一定意味着完全无法行动：可借款，满足条件时还可使用 [R09](#r09) 的贫困登船规则。

已付派遣费用是投入，结算时按结果领取收益；失败时没有投入返还。未用小人不产生收入。

<a id="r06"></a>
## R06：投骰、到港与受损

港务长投掷与本航程所载货物对应的骰子，按每枚骰子的结果移动对应船。原文允许港务长决定各船的移动顺序。

- 船必须沿自己的航线移动，不可换线或中途交换货物。
- 除了到港后的多余步数被舍弃，不能主动少走骰子步数。
- **越过 13**，就立即进入港口的下一个空泊位，依次为 A、B、C。
- 已到港的船不再航行，也不再受引航员影响。
- 第三次航行后，未到港的船进入修船厂，依次占 A、B、C；恰好在 13 的船先按海盗特例处理。

不要将“到达 13”和“越过 13”视作同一个到港条件：

| 情况 | 结果 |
| --- | --- |
| 第二次航行后恰好在 13 | 若有海盗，可发生登船；船仍在航线上 |
| 引航员把船移到 13 | 此时不触发海盗，也不立即到港 |
| 引航员把船移过 13 | 立即到港 |
| 第三次航行后恰好在 13，海盗船仍有人 | 被劫掠；海盗船长决定送港口还是修船厂 |
| 第三次航行后恰好在 13，海盗船无人 | 进入下一个空港口泊位，正常视为到港 |
| 第三次航行后未越过 13，且不属于上述特例 | 进入修船厂 |

<a id="r07"></a>
## R07：海盗

第一个派往海盗船的小人成为船长，第二个占次席。两席费用均为 5，可以属于同一个玩家。

### 第二次航行后：登船

仅检查本次移动结束后恰好停在 13 的船。

1. 海盗船长先决定是否登船，然后轮到次席。
2. 选择登船，就把该海盗小人移到一艘符合条件的船的空座上；这是海盗事件，不另付正常派遣费，也不消耗一次新的派遣机会。
3. 基础规则不能登上满座船。多船符合条件时，可以自行选择目标空座。
4. 海盗可以留在海盗船上，等待第三次航行后的劫掠。
5. 原船长离开海盗船后，仍留在海盗船上的次席立即升为船长。

登船的小人随后作为该运输船上的小人参与收益或承受失败，不再同时参与海盗船的劫掠分红。

### 第三次航行后：劫掠

若海盗船上仍有人，所有恰好停在 13 的船被劫掠：

- 船上原有小人全部返回各玩家，不能领取该船分红。
- 货物标注的整船收益由仍在海盗船上的小人平分；仅剩一个海盗时，该小人独得全部。分的是小人的份数，同一玩家占两席便领两份。
- 海盗船长逐艘决定被劫掠船送往港口还是修船厂。
- 送往港口的货物仍会涨价，港口岗位照常判定；送往修船厂则进入相应修船厂与保险判定。
- 若海盗船已无人，则没有劫掠，停在 13 的船按正常到港处理。

<a id="r08"></a>
## R08：引航员

发生在**最后一轮派遣结束后、第三次投骰前**，先小引航员，再大引航员。

- 小引航员：可选一艘未到港船，前进或后退 1 格。
- 大引航员：可选一艘未到港船，前进或后退最多 2 格；也可选两艘船，各移动 1 格，方向分别选择。
- 两位引航员可先后影响同一艘船。
- 每位引航员都可以放弃使用；一人放弃不妨碍另一人使用。
- 把船移过 13 会立即到港；只移到 13 不会立即触发海盗。

第三次骰子必须等两位引航员的机会处理完毕才能投出。小引航员确认移动后，大引航员看到的是已经更新的船位。

<a id="r09"></a>
## R09：贷款、赎回与贫困登船

### 抵押股票借款

持有未抵押股票的玩家可在需要时借款，每张得到 12。抵押状态要与普通持股分开记录，同一张不能重复抵押。

每张支付 15 可赎回；赎回后该股可再次用于借款。抵押不会把股票出售给银行，终局按 [R10](#r10) 的公式计入股值和未偿贷款。

应付款项不足时，需要通过可用贷款履行付款义务。竞拍金额不能超过“现金 + 可抵押股票数 × 12”；保险资不抵债另有银行补足规则。

### 贫困登船（原文 Blind Passenger）

- 玩家现金为 0，且没有未抵押股票可以借款时，可将小人免费放入运输船的合法空座。
- 此规则只提供登船机会，不是所有岗位免费。原文说明无现金时其他岗位暂不可选。
- 若把现金与可取得的贷款都算上，仍不足以支付最便宜的船位，可以交出剩余全部现金放入该船位。
- 仍须有小人、合法空座和派遣机会；不能登上已到港船，也不能绕过“本航程已放弃派遣”。

UI 应分别解释“需要先借款”“可按贫困规则登船”“确实没有合法位置”，不要只用一个笼统的“金币不足”封死操作。

<a id="r10"></a>
## R10：结算、保险、行情与终局

### 航程收益

全部船的去向确定后，按以下来源结算：

| 收入来源 | 领取条件与计算 |
| --- | --- |
| 正常运输 | 船到港，船上小人平分该货物的整船分红；同一玩家按自己的小人数领取多份 |
| 海盗 | 留在海盗船上的小人平分被劫掠货物的整船分红 |
| 港口 | 自己所占泊位有船，领取该泊位标注金额 |
| 修船厂 | 自己所占泊位有受损船，领取该泊位标注金额 |
| 失败投入 | 未到港的运输小人、空泊位上的小人、没有触发收益的海盗，没有相应收益 |

例如：玉石整船分红为 36，船上有甲的 2 个小人和乙的 1 个小人，则每个小人 12，甲领取 24，乙领取 12；不能按两名玩家各分 18。

引航员不另发现金奖励；保险的 10 在派遣时已领取，结算时不能再发一次。持股不会因每次到港自动获得现金分红，它影响买股价格和终局财富。

### 保险赔付

保险玩家对每个实际有受损船的修船厂泊位承担对应金额：A 为 6、B 为 8、C 为 15。

- 该泊位有小人：付给小人的玩家。
- 该泊位无人：付给银行。
- 没有保险玩家时，由银行支付修船厂岗位的收益。
- 保险玩家可以先领取自己本航程的其他收益，再付款。
- 不足时必须尽可能抵押股票补足；仍不足则支付能付的部分，其余由银行承担，银行垫付部分不形成新债务。

**修理费与修船厂岗位收益是同一笔赔付的金额和去向，不要重复扣两笔。** 例如两艘船受损，保险责任合计 6 + 8 = 14；不是再额外付一遍 14。无人占据的受损泊位也要赔付。

### 行情上涨与下一航程

- 本航程到港的货物各上涨一个印刷刻度：0 → 5 → 10 → 20 → 30。
- 被劫掠后仍被送到港口的货物也上涨。
- 没出航、受损且未到港的货物保持原值。
- 收益与赔付先结清，再呈现本航程的行情变化。
- 未触发终局时，收回全部小人，船和货物回到准备状态；现金、持股、抵押状态和行情保留，进入下一次港务长竞拍。

### 终局

任一货物行情达到 30，游戏结束。

```text
最终财富 = 现金 + 所持股票按当前行情计算的总价值 − 15 × 未偿贷款张数
```

按所查规则的计分文字，先计入所持股票的价值，再按未清贷款每张扣 15；不要把抵押股先归零后又扣一次债务。最高者获胜。平局如何展示见 [R12](#r12)。

<a id="r11"></a>
## R11：原文附带的海盗变体

该变体加强第二次航行后的海盗登船能力，**应与基础规则分开**：

- 可以登上满座船，移走一名原有小人并将其交还所属玩家。
- 但只要任何符合条件的 13 号位船还有空座，海盗就必须先使用空座；空座全部用尽后才可挤走人。
- 两名海盗登同一艘船时，第二名不能挤走刚登船的海盗船长。

项目尚未决定启用此变体。基础样板按“不挤走满座船员”制作，需要验证变体时使用独立预览，不混入默认规则。

<a id="r12"></a>
## R12：项目改动与待定事项

| 项目 | 当前结论 |
| --- | --- |
| 玩家身份 | **用户已确认**：角色代替颜色棋子，当前只区分形象与身份 |
| 专属技能 | 以后再定，不增加主动技能按钮、技能结算或平衡数值 |
| 人数 | 以原版 3–5 人为依据；六张可选角色不等于六人局 |
| 原版规则与样板 | 固定演示数据用于看 UI，不表示实现了完整规则，也不表示批准了规则改动 |
| 海盗变体 | 尚未选择，默认预览先采用基础规则 |
| 首航全部弃标 | 所查文字仅明确“上一任留任”；首航没有上一任的处理，需要采用版本补充说明或另定电子版约定 |
| 终局同分 | 所查文字只说财富最高者获胜；并列展示或额外决胜规则尚未确定 |
| 第一位竞拍者的电子版设置 | 原版按年龄；电子版是否用房主、随机或手动指定尚未确定 |
| 信息可见范围 | 初始股票明确不公开；先保护对手隐藏持股。现金、贷款等是否在公共 UI 直接展示，制作对应面板时确定，不因方便调试而默认全部公开 |
| 多人使用方式 | 同机轮流、联网、AI 对手尚未确定。先做本地身份与行动玩家分离的展示，具体交接方式以后接入 |

这些待定事项不妨碍先做美术和固定场景，但到对应功能时要明确标注选择，不能把暂用行为写成“原版规定”。
