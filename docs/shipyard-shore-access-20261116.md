# 修船厂人行石阶接岸 · 2026-11-16

## 后续用户纠正：重点是整组退岸与台基体量

用户随后明确“可以，按这样改”，整组退岸、降台及连接重整已实施，最新状态见 [整组退岸与降低石台](shipyard-setback-low-quay-20261116.md)。下文“尚未修改”为提出方案时的历史状态。

用户随后明确：台阶在前侧还是右侧都不是主要问题，关注的是整个修船厂是否应该后移，以及红框内前方整块石台/阶梯过高过厚、像积木玩具。下文已实施的五级人行石阶搬位是一次范围过窄的解读，不能当成本次问题已解决。

结合用户红框图和现有部件坐标只读核对：台面最高1.62米，面层厚约0.15米，三层承重石高度约0.50/0.52/0.524米。上一轮顺岸落位报告的约0.5米偏移采用局部 `y=-5.35` 参考线；实际铺地前缘 `y=-5.645` 和最外石基 `y≈-5.71` 更靠海，实际外缘伸出计算水线约0.8–0.9米。整齐的三层大石、连续厚盖板和两侧矩形台块共同放大了高台/积木感，不能只用纹理或局部倒角解决。

建议试改起点是保持顺岸朝向，整组向岸内后移约1–1.2米，同时评估降低作业台标高约0.5–0.7米及重整外露石基。只读采样表明，后移1.2米时前方石基外缘约在水线内陆0.28–0.34米，中央滑道末端仍在水线外约0.64米；因此能初步兼顾岸上作业台和船用滑道入水。降低时需要共同处理厂房落座、槽底、维修船/船托、侧阶和岸坡，不等比压扁整个模型。后排净空及降低后的通路还需实际验证。

这些是设计诊断和待验证起点，尚未修改运行装配或Blender模型，不是已完成的整组后移/降台，也不表示用户已验收原搬阶方案。
