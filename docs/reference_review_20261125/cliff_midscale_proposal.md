# 第三轮岩面中尺度补形依据

复看第二轮 `art_20261125_174751_728695` 的 civic、market、terrace 三个实机视角。橙土围裙已分开，箱组已离开岩面。现有三块大形需要保留；主要剩余问题是大斜面仍顺滑，材质中的斜灰面比实体切面更强，尤其酒吧—餐厅之间的后岩面，仍像平滑墙面上的色片。此判断不是视觉验收。

本轮不改变大形位置或整岸高度。`cliff25_relief_common.py` 手工放置10处有限的中尺度变形：Sea Breeze后两处短台口／凹面，医院四处相互错开的小楔与退入面，酒吧后四处短肩口／凹面。它们以实际岩面Z、H为坐标，长度约1–1.5米、厚度约0.5–0.9米，局部切角／退入形成约0.3–0.9米的有效面；不同高度、终止位置和正负方向，避免平行层带、重复砖块和全随机细噪。

几何仅改变H，实际增减不超过0.20米；每块保留短直线倒角和小倾角内面，以局部法线和遮蔽给材质一个实际形体依据。没有对三角面逐片flat-shade，也不增加孤立岩板。保护仍使用首轮完整路床／院地／楼板／树根／岸石／边界锁及距离淡出；草冠和坡脚不作为补形面。新箱服务位置在三组范围外。

`cliff25_01_sculpt.py` 仍从本轮不可变baseline生成原1443点大形，然后单次叠加有限细节。新增report和NPZ字段分别记录原大形和中尺度，避免重跑累计。首轮脚本归档为 `captures/cliff_contacts_20261125/iteration1_sculpt.py`。

离线提案数值读取实际sculpt结果后计算在另名文件，不覆盖MCP实际结果：预计181点/446面受影响，最大降低约0.183米、抬高0.177米；全锁点变化0。每块实际支持4–73个顶点，少于4点的初案已修整，未保留单点疙瘩。4点区因原网格沿岩面较疏，实际形状会由相邻较大三角面形成短楔，必须在实机复看，不将数值通过等同可用。

有限坡面法线有明确变化，预计受改面法线中位转角约7.3°、p95约26°，面坡度p95约72.4°、最大约76.1°。最大的约62°法线转动发生在原22°的细三角面上，新约51°，不是新垂直尖刺；仍应通过正常机位验证有没有锐小翼或贴补块感。若仍只有颜色而无体量，不应继续叠更多同类碎纹，需重新评估大形/材质对位。

此文件为实施前方案及只读数值证据。最终MCP执行与实机结果以父任务记录为准。
