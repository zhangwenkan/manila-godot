# 医院—Sea Breeze—酒吧：区域表面方案（只读诊断，2026-11-25）

本记录没有连接 Blender，没有修改运行 shader、纹理或模型。依据是当前 `791081…` 源对应的实际运行文件与 `art_20261125_154836_902035/` 实拍；本轮所有基础贴图仍由主代理在独立 GUI Blender MCP 中制作。下述值是试作起点，不是视觉验收。

## 当前问题的具体来源

- `reference_environment.gd` 完整绑定 G23 五表面和 G23_LandUse；当前区域没有启用 S23。历史“区域内 S23／区域外 R27”的诊断不适用于当前运行版。
- 最终 `ground23_21_rock_weathering.py` 将岩图改成 8m 循环的矿物噪声和 24 条浅裂纹，明确撤掉此前宽断面高度场。实际 G23_Rock 图是灰绿云状斑驳，几乎没有方向明确的层理或面之间的组织。其 sRGB 均值约 `[.408,.426,.390]`，P05/P95 为 `[.373,.388,.353]`／`[.459,.471,.431]`；缩成 8×8 的平均通道标准差只有 .01265。灰墙首先来自图案和真实面形，不能只提高 bump 强度。
- 当前正常镜头的医院下方整面灰岩、酒吧背面岩墙依然像连续屏风。S23旧图虽然有块面，但其横排与竖缝形成砌砖式网格；不建议恢复它，也不建议铺成新底图。
- 当前三平面按 `abs(normal)^4` 混合，8m岩高场范围 .24m。高度先分别求导再混合，没有对投影权重或地类权重求导，这一点是正确的，应保留。该流程不是造成灰墙的首要错误。
- G23_LandUse 的岩／土主要由平滑坡度决定，沙又主要由高度 .34–.52m决定。几何平行时自然得到平行色带。虽然正常贴图正确，只改配色仍无法改变其空间组织。
- shader 以 `leading_weight - .28` 竞争各地类，把大部分低权重接触完全压掉。它能消除大片半透明混色，却也使本来应呈覆土、零碎草根和颗粒分布的接触变成一条窄硬边。不能全局放宽这个值，必须局部画接触形状。
- G23_Path已有0.10–0.30m压实斑块和细砂粒，但4m平铺、全路用同一种分布，没有路中央与路边、院地与连接道的区别。Sand与Soil同样缺与当前位置对应的沉积和干湿组织。纹理并非完全不存在，而是缺位置和用途上的层次。

## 建议的最小运行接口

已写 `demo/tropical_harbor_3d/source/cliff25_shader_patch.py`，它只提供 `build_proposal(original)` 和输出审查候选文件，不会改活动 shader。新增2个采样器：`cliff_region_color`（sRGB），`cliff_region_height`（linear R float EXR），以及默认关闭的开关。启用后只替换岩角色的区域底色，并增加独立高度导数；其他地类仍由现有LandUse控制。仅新增2次纹理采样，不增加三平面重复采样。

两张图共享2048×1024图幅：主岩占U .02–.66，酒吧后岩占 .70–.98，V各占 .02–.98。PNG首行对应高处。两组之间留边，且不把层理穿过Z34–37的上坡连接口。

| 分组 | 世界映射（Godot） | 有效区域窗 |
| --- | --- | --- |
| 医院／Sea Breeze主岩 | `s=(z+.26*(x-20)-22)/12.8`，`v=(h-.9)/4.0` | Z21.8–34.3，主强度Z22.5–33.5 |
| 酒吧背岩 | `s=(z-.24*(x-19)-37.3)/8`，`v=(h-1.25)/3.4` | Z37.4–45.1，主强度Z38–44.4 |

X区域窗15.7–26m，16.7–25m全强度，且只乘实际岩权重。X斜向项让转侧面仍有少量展开，优于纯Z/H塌缩。它仍不是严格展开；若后续出现近乎沿Z法向的宽侧面，需检查其拉伸，必要时单独局部UV chart，不可单纯加密贴图掩盖。

推荐区域高度总范围 .16m，旧G23高度在区域内降到 .035m，仅作小矿物起伏。求导必须先对各自高度字段求导，再乘区域mask和岩权重，不对mask求导；大肩和轮廓由真实地形承担。不要恢复 .70m 假厚岩高场。候选脚本尚未在 Godot 编译或实拍，主代理应用时需绑定与验证。

## 颜色与层理的具体制作起点

主底sRGB `[.43,.445,.415]`；宽暖矿面 `[.49,.485,.43]`；冷灰侧面 `[.36,.395,.38]`；少量新破面 `[.55,.555,.49]`。裂隙暗部可到 `[.30,.33,.31]`，但不作包住每块的黑描边。这些是矿物／风化差异，不能把固定太阳方向的阴影烘进底色。

面级变化占主要对比，1–3m宽面可有8–16%的明度差，细噪声幅度控制约 .008–.015 sRGB。让大部分宽面内部保持平静；只在局部转折处出现 .03–.08m宽、.8–2.5m长的断续裂隙。正常镜头应先看见2–3大面再看见细裂纹。勿将纹理细节绘成等间距水平线和贯穿上下的竖缝。

主岩可参考下列两条“不完整层界”控制点（Z,H，实际与新几何转面再对齐）：

- 下层倾折：`(22.4,1.8),(24.3,2.0),(26.0,1.7),(28.1,2.45),(30.6,2.15),(33.4,2.7)`；只在Z22.7–25.4、27.4–30.7的局部显现，其余融合进宽面。
- 上层倾折：`(22.4,3.4),(24.1,3.25),(26.3,3.5),(28.1,3.1),(30.3,3.55),(33.4,3.8)`；可在Z24–28和31–33.6形成断续台肩。层间距不固定，不要求全墙都有两层。
- 酒吧后岩独立成组：Z38–40.4一个斜向宽面，Z40.4–43.8另一个回收面；在H2.45–3.0附近出现一段较弱中层转折，方向和主岩不同，但保持相同材料色域。

上述控制线不应直接作为有全长暗边的折线画出来。用其划分宽面、局部浅凹和终止处的破口，裂纹只是少数边段。

几何代理随后给出的 `cliff_form_plan.json` 优先于上面的初始层线：主凸肩Z27.5／29的中层真实转折约H2.63–2.89，Z30为H2.28–3.18的斜向面，Z31.5则H2.19后转到3.35；酒吧中层宽台只在Z40.2的H2.98–3.13和Z42的H3.2–3.3出现，Z38／43.8不复制同台。区域图应跟这套实际转面落位；Z29–31.5的侧回面应保持平静宽面，不再叠一条独立的假层线。

## 草、土、路、沙的接触

保留上一轮完整路床、院地和入口逻辑。新的地类占地图应在本轮几何范围内更新，范围外保留最终旧图。沿路肩把草边设计成宽窄不等的团块，部分完整干净、部分露根、部分被踩薄；不要给每条路加同宽深土描边。门前活动院地可有较大的压实片，连接道中央少量顺着走向的磨损；路床全宽不能因地类绘制又缩成断线。

岩冠以真正有覆土厚度的草肩为起点，在凹口里留0.25–0.60m宽的不等土袋；凸岩顶部较干净。岩脚局部0.4–1.1m宽扇状积土／小石地，靠建筑和通路须收回，不能沿整墙铺一条深土带。对应少量实际碎石与草根即可，不要拿岸石遮住错误边界。

草—沙由实际缓岸坡脚决定，沙向内陆进入低凹处，草在较高处以团块结束。改局部LandUse边界和真实坡脚，不能继续让同一0.34–0.52m等高规则决定所有岸段。干湿沙是受水缘和低凹影响的宽软变化，不是草边沿线新增另一条带。

若本轮还需要让路／草／沙在正常镜头有区域质感，可增加一张局部XZ区域表面调制图（独立scope，约X8–27/Z21–45），画压实面、草密度和低凹湿色。它只调整已有各地类内部明暗／色温，不覆盖地类边界，也不动正常光照。第一优先仍为大形和岩区域图，不能用更多全图噪声替代。

## 实拍判据

保持当前日光与机位。先看正常整屏里医院下方是否由一面灰屏变成有主次的宽岩体；再看近景是否有砌砖网格、贴图拉伸或浮在表面的暗线。岩冠不能新长绿锯齿，路床不能重新穿陡面。最后核对本轮新图真实缓存与独立源内图一致。技术通过与视觉结果分别记录。
