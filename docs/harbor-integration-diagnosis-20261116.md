## 核心判断

目前的主问题是整屏缺少统一的概括程度、视觉主次与空间连接。单件几何细节增加不自动带来整体协调，也可能使资产之间的差异更明显。此前逐栋、逐构件精修的推进方式对这些差异处理不足；环境补全后，不能继续用数量或技术检查代表整体美术成立。

### 1. 表现尺度不统一

参考图有草、木缝、绳索等细节，但首先读出树冠、屋顶、墙、船壳、货物的大体量。当前水面是连续通透的渐变，修船厂则集中压型槽、锈迹、窗格和构件暗缝；树林是重复的扁圆硬折面树冠，灯塔与保险区仍有占位式体块。画面并置了不同程度的概括。新增树叶数量不会自动解决树冠剪影和成组关系。

### 2. 海岸缺少跨越分区的连接

参考图的关系为水—码头/小船—作业地—土路—房屋—树林。码头跨水线，草坡与沙地有进退，工作物件沿用途散布，树与房屋相互遮挡。当前虽已补地面与道路，正常机位中仍突出宽空沙带、连续白色水线、完整露出的建筑台基；相邻物件仍像分别摆放。退岸降台已改善修船厂局部，但不能单独完成整条海岸的组织。

### 3. 色彩的角色不清楚

参考图冷蓝海水、暖砂/茅草/木材、绿色植被形成大关系，船壳与船舱有清楚明度分工，红绿货物与棋子承担高饱和重点。当前浅青水面很强，陆地与船货偏灰黄/棕灰，深蓝灰修船厂又成为孤立的深色细节集中区。问题涉及面积、明度、重复与重点分配；整体加饱和或统一乘暗无法替代这些组织。深灰蓝与重锈可以保留，并通过周边木作、石地、植被和船货层次形成联系。

### 4. 材质对光的反应与“台面感”

当前水体能看见大片浅底和清楚的船影、底座轮廓，岸地较平滑，树冠有硬折面和深色阴影，建筑上则有高密度的小阴影。这些尺度的差异会加强陈列感。共享太阳和色调映射不等于画面自动统一。截图不足以证明某一个 roughness、AO 或水体参数是根因；如需试验，应在同机位分别检验水深/投影读感、背景明暗与表面细节对比，避免一次改全部设置。

### 5. 构图与 UI 属于同一套视觉设计

参考图中船货占有足够画面面积，岸边工作区与其连续相邻；房屋形成背景节奏。当前起航图船队与右上厂房之间有较大的安静水面，厂房细节与深色又吸引注意，视觉容易分成船、水、岸、厂房几块。以后需要在当前受控机位与同步规则内设计环境的前后、疏密和开口，不能直接推导为扩大总览或拉近全部航线。

参考图 UI 用奶油白承接沙地、暖黄、深棕文字承接木作，圆润大形与棋子、货物一致；红绿按钮呼应交互重点。它还提前给场景留出显示位置。UI 可以与世界有不同绘制方式，关键是共享色彩、形状与信息层级。当前截图有隐藏 UI 的检查模式，不能把这种差异全部归因于现用 UI；沙盘菜单继续是记录方案，本轮不展开制作。

## 后续建议，尚未实施

先用正常游戏机位的一段“船—修船厂—岸后小屋与植被”建立整体样区，检查缩到原图约四分之一时的主次。优先顺序为：岸地/作业地的连续形状与连接；树冠、房屋、码头的成组轮廓和疏密；大色块与暗部范围；最后才是局部纹理和小构件。现有工业修船厂可保留，不能把本次疑问解释为要求全部改成低面模型或替换为茅草屋。

验收依据是正常机位能否一眼读为一段有人使用的海岸，以及船与当前功能区是否清楚。单件近景变精细、面数增加、技术检查通过均不能替代这一判断。
