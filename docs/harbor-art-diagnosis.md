## 1. 早期房子为什么像均匀色块（历史原型）

检查对象为 `assets/coast/harbor_office.glb`、`source/coast_06_loading_house.mcp.json`、后续构件修订和 `environment/coastal_town.gd`。

- **实际有贴图，但映射方式不合格。** 新房沿用了本项目桥的打包图集，将 UV 压进 `u = 0.065 + (u % 1) × 0.012`、`v = 0.12 + (v % 1) × 0.48`。对于 2048 × 2048 的图，这是约 24.6 × 983 像素的窄条；墙板和屋面反复使用同一区域。直接读取最新 GLB 也确认屋面 U 仅约 0.066–0.076，墙板 U 约 0.0652–0.0768。glTF 导出翻转了 V，不能把它误判成另一块纹理。
- **这不是“整张贴图只有 25 像素”。** 问题是各构件可用的横向表面信息很少，原图为其他桥板制作的方向、端面、节疤与色差没有对应到新构件上；即使文件名写着 2K，也不会自动变精细。正确设计的共享条带贴图可以高效复用，但不能任意截取既有 UV 图集的一条区域代替设计。
- **材质差异主要来自整体染色。** 最新 GLB 有 16 个材质，实际嵌入图像只有桥的 albedo / normal 两张；墙、屋顶、浅木和深木主要由 Godot 乘色区分。蓝色门、石基等没有颜色纹理。不同部位缺少符合用途的表面变化。
- **法线贴图也受同一 UV 问题影响。** 当前木材已有 normal texture，scale 约 0.65；不能把问题归因于“完全没接法线”。木材运行时粗糙度约 0.93，已经很哑光；把它继续调粗糙并不能补上材质内容。
- **造型重复强化了色块感。** 屋面板缝贯通、模块重复；附棚顶仍是整片板，附屋是整块主体；墙板、门框、木箱各自有边，但厚度、搭接、紧固与磨损缺少统一设计。桶像圆鼓形基本体，绳盘更接近规则同心圈。

当前整个 GLB 为 31,912 个三角面。多次倒角和重复小构件已经消耗不少面数，继续堆面不是关键；需要把形体预算用于屋檐厚度、接头、桶板、绳结、渔网垂坠等真正可读的特征。

## 3. 清晰、自然与整体和谐为什么同时成立

参考的细节以中等尺度为主：从远处读到屋顶轮廓与板材分区，靠近后读到木纹、门五金、绳股和桶板。它没有把所有表面都铺满细小高对比噪声。这能保持清楚的轮廓，同时避免脏、碎、闪烁。

当前截图为 1600 × 900，所用参考视频帧为 1280 × 720；二者镜头和物体屏幕尺寸不同，不能直接比较单位尺寸解析力，但这足以说明“只把窗口开大”不是解决当前缺失细节的办法。图中墙板接缝已经能辨认，仍显粗糙，问题首先是板面内容与构造。后续再单独检查纹理像素密度、mipmap、斜面过滤、阴影分辨率和截图显示缩放，不能用锐化制造假细节。

配套和谐来自有约束的共同设计：木板厚度、绳径、桶和箱的尺度相容；木纹相对物体的大小接近；边缘倒角和磨损强度一致；暖木材、少量蓝色油漆、麻绳与暗铁各有角色；物件的绑扎、支撑、堆放有用途。它不要求所有物件套同一颜色，也不要求每个角落都加道具。

当前房屋的侧面和檐下偏暗，会掩盖细节，光照仍有调整空间。但桥与房屋处于相同环境，房屋本身又已确认存在 UV 和构造问题，不能先靠统一提亮或加重 AO 掩盖资产缺陷。先让材质本色及构造成立，再检查固定白天光照下的投影和接触关系。

## 5. 下一步只解决一个样区

目标是完整的“一栋货仓 + 相连平台 + 木箱 + 麻绳 + 渔网”，不是再批量做其他房子，也不是继续只改水。所有建模、UV 与 Blender 资产编辑仍通过隔离的 Blender MCP 会话完成，保持与用户另一个 Blender 项目隔离，不使用 HD-2D 技能。

1. **先设计构造。** 确定板宽、梁柱厚度、屋檐厚度、屋面搭接和门窗嵌入；修改整片附棚与块状附屋。保持适度不规则，不能靠随机扭曲每块板制造旧感。
2. **重做贴图分配。** 建立适合建筑的图集或经过设计的共享条带；长木纹顺板材，端面单独处理，木箱、绳索、桶各有合理映射。保留板内低频变化、少量木纹和节点细节，避免过密噪声。先对一个屋檐转角、墙板和木箱做实际尺寸验证，再覆盖整栋。
3. **把道具做成物件。** 木箱有板拼、框条和紧固关系；桶有桶板、桶箍与端盖；绳有自然盘绕、末端与绑结；网有固定点、下垂、疏密变化和厚度。大形与轮廓用几何，细绳股和浅凹凸由贴图/法线承担，不做每根微纤维。
4. **统一到既有船桥。** 依据世界尺寸检查板材与纹理尺度，统一色彩、边缘和磨损程度；货物靠装卸区域，网挂到实际固定点，保留门口及通行空间。
5. **再检查光照。** 在现有固定白天中检查门窗凹陷、屋檐、箱底、桶底、绳网投影与水面反射；不把方向性太阳阴影画死到颜色贴图里，也不通过整体加黑来制造体积。

验收必须来自唯一 `fleet_harbor.tscn` 入口：同一次运行保存总览、近似参考俯角、低角度船侧与建筑侧背面的画面。检查远处能辨认用途，近处材质不会变成拉伸条纹，低角度有真实结构，船桥和房屋比例相容，道具不悬空、不穿插；相机和航行测试通过不能代替用户视觉认可。样区认可后才恢复全港计划。
