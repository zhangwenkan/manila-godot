# 修船厂沿岸落位 · 2026-11-16

用户指出修船厂整组朝向没有顺着岸线，并明确“按这个方向推进”。本轮优先处理厂房/石坞整组朝向、位置与侧后接岸；保留已确认组合造型、深灰蓝重锈、船桥、水体和三船同步规则，不扩建其他建筑。

制作方案：以石坞约8.6米宽的临水前缘对应岸线为依据，先将Godot整组朝向由-60°改至-81.5°，位置由(11.5,0,34)改至(11.15,0,34)。使前缘大致平行这段岸线，维修槽朝海；再通过独立Blender MCP修正旋转后土坡外缘与原沙地的高差，检查石阶/通路及道具落地。

先保留现有游戏机位、光照和航线，使用原机位对照判断摆放关系，再单独处理起航机位。备份在 `demo/tropical_harbor_3d/captures/shipyard_alignment_20261116/before/`，包含上轮最终源、GLB、装配、航线与专项检查脚本；后补了镜头类、主入口脚本及沙地shader备份。

## 已完成的落位与接岸

- 修船厂整组由-60°改为-81.5°，沿X向海侧移动0.35米，Z位置保持34。厂房、石坞、维修船、滑道、木梯与道具一起调整，构件之间原有连接关系保留。只修改Godot装配，没有在引擎造网格。
- 以前缘局部坐标 `x=±4.3, y=-5.35` 对应的水线为参照，原两端沿世界X的水线偏移分别约-1.31/+1.98米，差3.29米；现在约-0.507/-0.503米，整条前缘在水线外侧约半米。中间采样约-0.556米，保留岸线自然弧度，没有把整条海岸拉直。
- 原土坡按-60°落位制作，旋转后外缘局部高出沙地约0.63米。通过新开的独立Blender MCP会话（PID16260、端口9878、核对本项目源文件）调整现有土坡1014个顶点：外缘接到当前沙地之下约14毫米，向内部保留既有台地。外缘顶点色也过渡回沙地底色，消除可见薄片裂口。
- 2711顶点/5146面的土坡范围和拓扑保留，未补回已删除的海床外围面。三道侧阶、上轮斜面入口石、箱堆、锚和铲子接触处的地面标高保留。
- 原7簇植物保留位置、网格、UV和材质；其中前侧4簇随新坡面降低，后侧3簇高度不变。没有扩建植物、房屋或其他建筑。

源仍为 `demo/tropical_harbor_3d/source/harbor_coast_mcp.blend`，默认导出仍为 `assets/coast/shipyard_combined.glb`。3080个可编辑对象、51网格、255959三角面，与上轮数量相同。原屋面、窗格、铁皮、石木构件和材质保留，61张内嵌图像逐字节一致，没有新增贴图。

## 起航机位

先保存了建筑转正、土坡贴合后的**原机位对照**，确认摆放变化本身成立。转正后，原初始机位看门面的水平夹角会大于原有“正面四分之三视角”的检查范围，因此再配合调整镜头。

起航段机位沿X向外海移动6.5米；进度3至6.5之间平滑回到原镜头偏移，6.5之后沿用原镜头。初始眼点由约 `(3.5,18.5,63.9)` 改为 `(-3,18.5,63.9)`，水平偏航由约9.5°改为-8.13°，仍从船后沿航向观察，FOV 48°、高度和纵向距离保留。查看修船厂时，取景中心读取实际装配位置。

`harbor_route.gd` 中只有相机 `offset()` 改变，物理航线的 `center/spacing/point/heading` 等函数与备份完全一致。没有移动航道、调整骰点规则、拆开三船播放或放宽既有取景断言。
