# 货轮与吊机整体缩小 · 2026-11-20

用户反馈“精度暂时可以”，但相对其他建筑过于庞大。本轮保留上一版细节、颜色、形体及朝向，优先纠正整组尺度；此反馈是当前精度阶段性认可，不能继续把上一轮所有细节都记成已被否定。

通过独立 Blender MCP 将当前 `Reference_CargoPort` 的2680个组件，以 Godot `(14,0,59.2)` 的水面位置为轴心统一缩至 **65%**。吊机最高点由16.78m降到10.91m，船长由18.4m降到11.96m，船宽约5.44m降到3.54m。邻近店铺屋顶高度约6.7–7.3m，吊机仍高出一截，但不再是原先两倍以上的体量。货轮船楼端继续垂直朝海，吊机继续平行海岸；正常游戏镜头没有移动或拉远。

泊位岸壁、护舷、基础、系缆同步缩放。原过大的岸内水域收窄、缩短，恢复腾出的岸地并向低岸壁渐降，共调整253个现有地形顶点。船底235次顶点/面心采样最小海床余量约0.767m，无相交。没有为缩小而简化网格、重绘贴图或改变楼层比例。

源文件仍为 `demo/tropical_harbor_3d/source/reference_harbor_mcp.blend`，运行更新 `assets/reference/cargo_port.glb` 与 `terrain.glb`。船港18网格/270485三角面、29张内嵌图像字节与缩放前一致；原UV和材质保留。12414个其他已有网格组件哈希一致，`town.glb`、`coast.glb`、`foliage.glb` 逐字节不变。三条物理航线、三船同步及真实A/B/C保留。

缩放前源、GLB与检查脚本备份在 `captures/cargo_scale_20261120/before/`。脚本 `source/cargo_scale_*.mcp.json` 是本次有状态轨迹，不可重放。源已干净保存，当前独立 Blender 已正常关闭；另一项目 Blender 和原 Godot 编辑器未关闭。`.blend` 继续仅本地保存，由 Git 忽略，没有提交或推送。
