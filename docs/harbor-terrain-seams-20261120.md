# 土坡接缝与草皮贴合修复 · 2026-11-20

用户指出上一版土坡断断续续、草皮局部凸出，要求精细检查地形。本轮沿岸检查酒吧/码头、餐厅—杂货店、横向上坡路、贸易行—礼拜堂、上层街道和后坡。继续使用真实独立 Blender MCP，保留本轮前完整源、地形、材质/高度查询及镜头航线备份。

## 发现与处理

- 基础土坡焊合原材质拆边后，没有内部开口；看起来断裂的部分来自按坡度逐面赋色形成的锯齿边界。仅对裸露坡壁做两轮小幅侧向顺平，1116 次顶点更新，避开建筑地坪、货轮泊位、海岸、石阶和横向通路。土壁过渡数据在 Blender 中写入共享顶点，运行材质据此连接土壁与坡肩；原实体高差继续保留。
- 原草皮用坡顶高度支撑位于坡面外侧的顶点。逐点检查发现多块前缘离底地约 0.8–1.426m，后坡另有约 0.157m 穿插。27 块草皮重做前缘、坡顶落点、渐薄后缘及埋入地面的根层/底面，避免窄尖端把搜索限制在原错误宽度内。
- 顶点正确不代表面内贴合；进一步移除 747 个跨坡、跨度异常或面心离地的顶面格，重建侧面和底面。保留草叶重新投到实际草面，移除超出支撑范围的草叶，清除横向坡路旁的绿色长尖片。两处仅在一点相碰的草皮拆开独立连接，27 块最终均闭合。
- 土壁权重最终确认为 GLB `COLOR_0`。中间 `COLOR_1` 导致整片沙地变土色、远景顶点色变黑的版本已修正；不作为最终成品。

本轮只改变地形及对应高度查询/运行材质；船、货物、货轮、码头建筑、植被、岸石、小镇和海水共 11 个 GLB 与上一轮最终审计哈希一致，镜头/航线逐字节一致。所有原有网格组件中，只有 `Shore_ContinuousGround` 的几何哈希变化；旧草皮保留在本地隐藏归档，新草皮另建。
