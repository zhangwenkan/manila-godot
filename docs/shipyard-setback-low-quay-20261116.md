# 修船厂整组退岸与降低石台 · 2026-11-16

用户纠正此前只搬动人行台阶的狭窄理解：重点是整个修船厂向岸内后移，以及前方石台过高过厚、像积木玩具。用户明确“可以，按这样改”后，本轮通过独立 Blender MCP 完成退岸、降台和配套连接重整。

## 已实施

- **整组后移1.2米。** Godot `RepairYard` 从 `(11.15,0,34)` 改为 `(12.35,0,34)`，保持-81.5°顺岸朝向。原前方石基外缘在水线外约0.8–0.9米，现约在水线内陆0.3米；中央滑道末端仍约伸到水线外0.64米。这里水线指现有岸线函数，画面中的泡沫带有宽度。
- **前台降低0.6米，厂房降低0.5米。** 主作业台面从1.62米降到1.02米，厂房地板从1.6米降到1.1米。厂房后部原沙地最高约1.058米，采用0.5米降幅，避免地面穿进室内。建筑与道具保持原比例，没有把整组等比压扁。平台后端逐渐抬接厂房入口。
- **降低外露石基，减薄铺地边缘。** 三层高石改为窄埋脚与两层不等高的承重石：埋脚 `-0.18–0.10`、中层 `0.12–0.45`、上层 `0.475–0.925` 米，靠后部分随岸地自然埋入。原16块工作铺地从约15厘米厚收至约10.5厘米，保留大板组织；承重石按原1.6米纹理尺度重排UV。
- **人行连接随台地降低。** 前侧原五级台阶收为两级，顶面分别0.88/0.74米，末端沙地约0.611米；原侧后宽阶改为三块连续缓坡铺石。三块门前石重整为通向厂房的缓坡门槛。六件多余的高阶石/承托块移入源内隐藏归档，当前导出不再使用。
- **中央维修槽保持接水。** 直接整体下沉会让槽底进入后方沙地，因此槽底和两根轨木改为随岸地向海缓降；槽底从前方约0.44米升到后方约0.965米，始终高于现有沙地。29条横枕随坡落位，船托下端接轨木。维修船作为完整组件下降0.2米，保持原船形及与托块上端的接触；船底与托块顶同为约1.19米。
- **重新贴合岸坡与道具。** 现有土坡2536个顶点重设标高，2711顶点/5146面及占地拓扑保留；外缘接入新位置的沙地之下约14毫米。7簇植物重新落地，侧面箱堆、锚、铲子按实际地面修正接触高度。

所有网格、UV和源文件编辑均通过核对后的独立 Blender MCP（PID37852、127.0.0.1:9878）完成；Godot只改整组装配位置及验证工具中的实际构件取景点。固定白天、相机、物理航线、三船同步规则、水体及现有沙地shader保持原样。沿岸其他资产未扩建。
