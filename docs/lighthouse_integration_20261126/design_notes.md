## 领航员规则边界

依据项目`docs/manila-rules.md`的R02、R03、R06、R08：

- 小引航员派遣费2，大引航员派遣费5；两者不另发现金收益。
- 时机为最后一轮派遣结束后、第三次投骰前；小引航员先、大引航员后，后者看到前者已更新的船位。
- 小引航员可选一艘未到港船前进或后退1格。
- 大引航员可选一艘未到港船前进或后退最多2格，或选择两艘船各移动1格，方向分别选择。不能把大引航员固定成一船+2。
- 两位可先后影响同一艘船，各自也可放弃。已到港船不可选。
- 移过13立即到港；只移到13，此时不立即触发海盗。第三次骰子须等两位引航员的机会处理完。

这里复核的是项目现有规则记录。该文明确来源为UltraBoardGames转载，非发行商官方中文说明书；本轮没有取得新的出版社原版文件，不能把本笔记称作出版社规则复核证明。现有文字未明确低于0的特殊处理，不补造截断或边界规则。

用户希望未来+1／+2由灯塔射光表现，−1／−2的演出尚未确定；这不是删除后退规则的授权。本轮仅做灯塔地标。灯室可预留独立灯盘／反光镜及朝向轴，后续光束与目标船关联；不现在添加规则触发、强制正向、自动移船或完成后的演出结论。

旧布局文档已指出：船可相距很远，不能因灯塔位置或光束长度添加“必须靠近才能引航”的新条件。灯塔是否与所有船同屏也不是领航合法性条件。

## 当前资产已核实的材质

| 灯塔部位 | 可复用材质 | 使用建议 |
| --- | --- | --- |
| 奶油灰主塔 | `Ref_TR20_ivory`，局部`Ref_TR20_plaster` | 宽面色差和少量修补，保留收分轮廓；避免纯白圆柱。 |
| 海军蓝帽盖 | `Ref_TN25_NavyRoof` | 终点已用的独立海军蓝材质，原设计色约#3D6275；正常法线强度约0.26。 |
| 低饱和门色／小点缀 | `Ref_TR20_teal` | 当前新建初稿使用青蓝门及灯室基座；不把早期锈红条带建议固定为灯塔识别形式。 |
| 门框／小维护桥 | `Ref_TR20_wood`、`Ref_TR20_deck`、`Ref_TR20_beam` | 与终点蜂蜜木、甲板及承托一致；木纹沿构件长轴。 |

| 灯廊栏杆／门铰 | `Ref_D19_ForgedIron` | 当前为非金属化的哑光蓝灰铁，roughness约0.67；保持窄而可读的轮廓。 |
| 灯盘／铜镜框 | `Ref_D19_AgedBrass` | 当前roughness约0.66、metallic=0，适合作小面积暖色。镜面效果需要独立新材质，不能因名称AgedBrass就假定已有镜面。 |
| 绳、泊船小环 | `Ref_Rope` | 与现有码头统一，只布置确有连接关系的少量构件。 |

**玻璃需要单独处理。** 当前`Ref_Glass`在实际GLB中为`alphaMode=OPAQUE`，roughness约0.84、深青蓝底色。它适合小镇内退暗窗，若直接包住八角灯室会挡掉灯盘和铜镜。灯室应使用独立新玻璃材质／少量清透窗片并在实际导出后检查；不得就地改变所有小镇窗材质。灯心暖光也需独立对象和材质，不把现有`Ref_Town_lamp`的名字当作它已带发光的证明——当前GLB没有emissive字段。

当前木／墙／石法线强度约0.48，屋面／红漆约0.26。已有贴图不等于应继续加深细纹；正常航行距离应先读出塔身收分、灯廊、八角灯室和帽盖。

`wall`的真实开口／约0.19m墙厚处理可供平面门洞理解，但不能直接套到收分圆塔。旧`roof`是双坡屋顶，终点最终又换为四坡曲顶；八角灯帽应按自身径向构造重做，复用海军蓝材质和边缘厚度即可，不直接搬终点屋顶网格。

圆塔建议使用周长角度U与高度V：侧面U按累计周长／实际纹理尺度，V按高度／尺度；跨缝面逐loop修正U到同一连续区间，顶／底另用平面UV。塔体显著收分时按分层真实周长或展开弧长组织，避免把主轴投影的四处方向跳变误当石缝。八角窗、帽盖面各保独立连续UV；木件仍使用现有长轴方法。

## 早期比例建议与当前实施方向

下列尺寸只是本轮开始时、尚未落位的比例探讨，未获验收。最终新塔采用八角收分木框暖灰墙塔、独立蓝帽盖、铁栏灯廊和透明灯室；没有依照旧二维图制作。已正式落位Godot`(5.5,0,15)`、yaw0°，水上最高9.63m，含水下礁脚总包围高约11.421562m；最终尺寸应读主记录与`independent_asset_audit.json`，不能将下列建议或`build_first.json`的初建状态当作完成尺寸。

可先以总高约10.2m作为9–11m目标区间的起点：低礁与砌石基座至Y约0.7–1.0m，收分塔身至灯廊Y约7.1m，八角灯室至约9.0m，海军蓝帽盖和顶饰至约10.2m。塔身外径约2.5m收至1.9m，灯室对边约2.2m，外挑灯廊约3.0m；这些是候选比例，不能当最终世界坐标或航道通过结果。

约5m底座应理解为包含外露礁石的最大外包候选。窄维护桥也必须计入完整占地，不能先以5m岛礁通过检查再额外向航道伸桥。海面以下做真实裙边或礁脚，平台上有能走到塔门的短路径；少量台阶与系缆点沿一侧组织，不让桥和石块分散围满整圈。

主塔采用当前小镇的木框与暖灰墙宽面，收分依靠真实八角轮廓、框架和分层承托；底部少量石基础、门窗实厚与内退建立重量。八角灯室有真实立柱、玻璃框、环廊和暖色灯盘，灯心从普通机位读成集中暖点。蓝帽盖采用新径向轮廓、少量接缝和有限外挑，不搬旧灯塔屋顶，不以旧图条带或轮廓作设计捷径。

岩礁需要主承托块、倾斜肩和低水边相互嵌接，不做规则圆盘上摆一圈碎石。新塔应接续终点暖墙／海军蓝和海岛岩色，减少写实锈斑、刮痕和密集砖缝；该建议不是对旧岩壁的重新制作授权。

## 空间核对交接

当前`fleet/harbor_route.gd`仍定义`LIGHTHOUSE_PROGRESS=7.5`，`lighthouse()`取中／右航道此处位置均值，中心间距函数在7.5附近为8m。这个函数事实只提供调查起点，不证明新约5m底座能放进去。不要从旧文档3.3m或旧4.3m底座反推本轮净空，也不要擅自改现有航线给新塔让位。

新模型检查应覆盖真实三船包围体、转弯、浮动、前后退及不同船距；礁脚／维护桥／栏杆外挑都计入几何范围。屏幕检查另看关注船船头、舱与货物，不能以“在屏内”代替无遮挡。先验证普通航行机位，再考虑未来独立领航演出；不因灯塔是地标就拉远所有普通镜头。
