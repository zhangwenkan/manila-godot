# 修船厂临海踏步延伸与浸水段 · 2026-11-16

用户认为上一轮整组退岸、降低石台后“确实更自然一些了”，并要求临海台阶再延伸一段，实际做出水下部分。本轮沿中央维修槽的木踏步继续向海延伸，保留已降低的岸上石台、人行连接与整组位置。

## 实施

- 中央踏步从4级增加到7级，向海延长0.96米。沿用3米宽、30厘米进深、12厘米厚的木构件，未增加岸上高底座。
- 七块顶面依次为水面以上0.36、0.27、0.18、0.08米，以及平均水面以下0.005、0.065、0.125米。最后三块包含真实顶面、侧面、底面；末端顶面角点距现有浅海沙底最小约2.8厘米，木料下部局部埋入沙底。
- 两侧原承托木改为分段随坡下降，共四段支撑；保留20×23厘米截面。长面按实际构件长度裁取已有木纹图集，保留端纹与物理纹理尺度。
- 新增三块浸水踏板使用较深的湿木本色，保留原法线、粗糙度和UV。`U16_WetSlipway_albedo` 为4096×1024，实际保存PNG的RGB约为原图58%；这不是经独立验证的“线性亮度比例”。两个Godot导入路径均使用显存压缩。
- 所有几何、UV、Blender材质与图像修改通过核对后的独立Blender MCP（PID18992、127.0.0.1:9878）执行。外部脚本仅负责通信、只读审计和截图排版。

当前3079个活动可编辑组件。修改5个已有构件，新增3块踏板与2段承托；3069个未指定原构件的变换、网格、UV和材质哈希一致。整组仍位于Godot `(12.35,0,34)`、朝向-81.5°；厂房、岸坡、石台、其他资产、航线、航行镜头、水体及沙地shader未改。验证工具只新增一张水边近景取景，原有机位保留。
