# 新电脑续作：局部岩肩、入湾通路与共同院地 · 2026-11-21

本轮从 11 月 20 日精简接续包恢复最新 `harbor_shore_control_mcp.blend`（C25 控制网格源），在真实独立 Blender MCP 中继续调整酒吧、餐厅、学校附近的岸坡、院地与接地关系。改变集中在一段岸坡：后高台增加局部岩肩与回折，临海入口改为斜向进入共用低院的渐窄通路，供应堆与长凳让开通行空间，植被和岸石重新落地。

正常游戏镜头中的变化仍属局部。岩面仍有大片灰墙感，树冠也较规整；本轮运行和几何检查通过，不表示已达到原作参考或得到用户视觉验收。

## 实际修改

`shore_21_02_landform.py` 从现有 C25 共享边界继续设计，而非另叠一层地表。首轮调整 499 个控制点，在约 z39.2–48.8 的后高台回折处分别安排坡脚、岩肩前缘、肩后缘与坡顶；中段保留短草台肩，让高台侧面出现局部宽窄变化。没有沿整条海岸铺设等宽新色带。

临海入口替换原局部 168 面，重新建立共享外圈的斜向通路：从海滩侧较宽入口向低院渐窄，海滩至院地的五组控制断面高度约为 0.27、0.34、0.53、0.87、1.18m。道路左右边进入实际拓扑，外侧地形沿旧外圈接回；后续收缓两侧土肩，避免入口成为一条突兀的直坡带。

`shore_21_04_finish.py` 收低局部回折坡顶、修复上院受移动影响的三角化，并将一组供应箱桶、叠箱、绳圈和麻袋移到院地东侧；长凳移至院地上端，让开餐厅墙面与通路。既有灌木和岸石集中到岩肩、坡脚及入口侧缘，局部树组完整重接地。草叶只保留在真实草面且法线较朝上的地表，清除落在陡壁或非草面上的部分。

部分资产的网格坐标已含世界位置，缩放后仅平移物体原点会改变预期中心。`shore_21_06_correct.py` 据实际包围盒中心重新摆正相关灌木与岸石；该步对旅行社前方承托地面的矩形范围调整遗漏了一个关键顶点，最终由09步补全。建筑模型、货轮与吊机本身未改。

最终 `shore_21_09_close.py` 修复入口约束线交点处的接缝：移除跨越两个 T 接头、与邻面重叠的旧三角形，以两个共享交点的三角形接回，保留原相邻三角形。局部开边断言通过后才写回网格。同时将旅行社楼板下方涉及的 3 个承托顶点恢复至 4.14m，并对楼板全部顶点位置重新检查地表支撑。

## 中间失败与最终状态的区别

06 步中的普通 `holes_fill` 没有真正关闭该接缝；不能因为调用返回或随后导出就把它记为已修复。07 步尝试拆分、合并并补面后，`Shore seam remains open` 断言触发，执行停在 `bm.to_mesh`、导出与保存之前，该次临时 BMesh 修改未写入运行资产。随后通过只读诊断识别出跨约束交点的重叠三角形，最终由 09 步按共享交点替换完成修正。

`art_20261121_190325_733507/` 是首轮材质复看；`art_20261121_192128_865485/` 虽有 33 图、17,525 项运行检查，但仍早于最后接缝和旅行社承托修正。它们均为过程证据，不是最终版本。

## 最终验证

最终完整实机目录为 `demo/tropical_harbor_3d/captures/art_20261121_192859_405671/`。`final_capture.log`、该目录 `art_result.json` 与 `preview.log` 确认 33 图、17,483 项检查通过。仍从唯一主场景运行，使用不可见 Windows desktop 的真实 Vulkan 渲染并限时退出；不是编辑器 F5 验证。

完整检查覆盖三条实际航道的碰撞扫掠、航道间距、沿线镜头遮挡、开场三船完整可见及左下至右上航向、三船同步、暂停、反向航行、点选、受控镜头与真实 A/B/C 分配。它不代替建筑接地、地形拓扑或视觉评价，因此另通过 Blender MCP 运行 `shore_21_05_audit.py`；最终结果保存为 `captures/shore_refinement_20261121/geometry_audit.json`。
