# 岸坡再次否定：轮廓拓扑与共同院地 · 2026-11-20

用户再次否定L24，说明换了坡顶/脚位置并未建立合格场景。实际重看四张实机和原作岸崖，确认高台仍如灰色斜幕、店前土坎像等厚长台、草沿软盖、道路如直滑梯、树石灌木孤立。

技术根因：L24最终仍在0.32m抖动网格上采样坡高；真实冠线/脚线没有对应拓扑边，材质阶段又全面平滑并删除sharp_edge，最后按颜色阈值修草沿。因此不再只改坡度、混色或阈值。

本轮在独立Blender MCP新源 `source/harbor_shore_control_mcp.blend` 中集中处理酒吧、餐厅、旅行社与杂货店前后约z37.5–60.5的岸段。外圈复用原地形边界，内部移除旧面，按真实冠线、坡脚及少量中间转面直接建面；宽台地/共同低院用约束三角化填充，与岸壁共享边线。草土岩按面与实际折边分配，旧源保留，本轮备份 `captures/shore_control_mesh_20261120/before/`。

## 本轮制作

先切出z约36.5–62、d约0–24.5的局部范围，复用真实外圈。内侧冠线、坡脚、岩肩、短台肩以共同站点直接桥接；低院与高台用Blender约束三角化连接。材质在真实边环与面上赋值，草沿不再跨普通三角面推算；岩面保留32°以上折边、浅面内部使用平滑法线。

酒吧与餐厅之间原窄尖楔后撤为宽岸肩；入口在两店之间接共用低院，上行路沿侧面折行，具有显式道路左右边。道路重布网调用超过MCP通信等待时间，后经只读核对已于17:10保存导出；独立进程恢复后确认源无未保存改动，没有重放有状态建模。后续UV赋值改为批量写入以避免长时间逐循环操作。

首轮灰模 `art_20261120_165001_937556` 19图；首次材质复看 `art_20261120_171703_523478` 23图发现旧草簇悬挂、细绿脚线、部分道路侧面绿色拉伸，已针对修改。实际岩面仍简化，不能把轮廓更清楚称为已达到原作。

两组既有岸石与庭院灌木重新组合到岩脚和低草带，大小互相搭接；旧小草按最终真实草面与法线重新落根，壁面草叶剔除。建筑和道具完整组重接地，保留原建筑造型。
