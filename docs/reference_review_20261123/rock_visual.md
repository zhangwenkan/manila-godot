## 新资源证据纠正：并非所有块面都应雕成几何

实际看 East Albedo 缩图后，可以直接确认：一张区域主图中同时画有草地、灰色岩带、河口、沙地及水边；岩带已经包含沿其走向组织的宽层理、短分界与成组深浅面。这些结构**确实存在于底色像素中**，不能再把实机看到的大块明暗一概归因于网格朝向或真实倒角。

只读核对 `F:/钓鱼游戏analysis/update_2026-11-17/exported_all/materials/M_TerrainEast_Demo__sharedassets2.assets_110.json`，`_BaseColorMap` 指向 Albedo 413，`_NormalMap` 指向 Normal 191，`_MaskMap` 指向 Mask 399，另有 `_RockDetail` 296；四者属于同一个 `Shader Graphs/TerrainEast` 材质。并行运行资料审计还确认主图为 4K、Clamp，RockDetail 为 512、Repeat。本视觉复核已看底色与 Detail 缩图并核对材质绑定，未单独查看 Normal/Mask 全图或还原它们的每通道算法。

因此证据支持的组合是：**宏观真实高差与轮廓 + 按地区组织的颜色/法线/遮罩主图 + 辅助重复细节**。前一版建议中“靠宽面和倒角产生明暗”的表述只适用于轮廓、真实厚度和大遮挡，不应扩展成“把每块岩层都建成几何”。主图里的深浅色是否由手绘或烘焙而来，原作每条裂缝的几何贡献，以及主图 Normal 与 Detail 的精确混合方式，仍不能由当前证据断言。

当前实现的直接对照：`source/rock21_05_surface.py` 为一张小图生成三条横缝、五条短竖缝和噪声；`materials/landform_mass.gdshader` 将岩石底色与高度按 3.2 米三平面重复。这可以提供表面细节，却缺少跟随酒吧后岩肩、凸岸头、凹入口分别设计的区域块面组织。不能仅把这张重复小图的凹凸加深，就期待得到原作区域主图的结构感。

## 五个具体差异

### 1. 原作也有连续立面，差别主要是面内部的体块组织

**实见：** 原作 20 秒图左上岩岸是一段连续立面，并非处处由谷口隔断；立面有宽而鼓出的块面，横向分层与短竖向分界组合。瀑布两侧则进一步形成前后错开的岩柱、短肩和侧面。当前酒吧右侧近景，除整体灰面向前鼓出外，主要读到同一张面上的软凹线，缺少足够宽的朝上面和侧转面。

**判断：** 继续增加沿岸凹口或把一整面起伏加大，并不必然得到原作岩体；需要把现有可见岩面设计成少量明确的厚块与转面，并为这些区域安排不同的颜色与法线块面。其内部块面并不都需要额外网格。瀑布的大方柱是特殊地点，不能沿岸重复复制。

### 2. 当前裂纹像软刻痕，原作裂纹帮助解释块体

**实见：** 原作普通岸崖上，几条横向分界跟随宽块面的上下边，竖向分界短、错位，部分在转角处终止。瀑布岩柱的大面较平整，边缘转折与缝的位置相互对应。当前近景岩缝多为细长、圆滑的下垂凹痕；正常镜头下则缩成重复皱纹，不能说明是哪一块岩体凸出。

**下一步：** 先以单色检查必要的大轮廓和转面，再在针对该段的主图中组织宽层理、深浅块面与断续缝，配合区域法线。每个大面内部应保留安静区域；不靠加密重复裂纹、加深所有凹痕弥补结构。

### 3. 冠线与脚线需要清晰转折，当前过渡让岩面像被绿雾覆盖

**实见：** 原作草顶与岩壁交界较窄，整体弧线包含少量宽缓起伏；岩脚转入低草地也能读到明确接触。当前近景冠沿有许多尺度相近的小齿与柔化绿边，脚部灰绿混合较宽，岩面上、下两端的转折被冲淡。11 月 21 日修掉的真实薄片和拉丝不再出现，但材质边缘仍软。

**下一步：** 保留几处宽尺度冠线高低变化，减少等密小齿；让草顶与岩面以窄接触边相交，草只在有面积的岩肩或脚边积聚。该收边的地方收边，不把全沿岸都处理成同一宽度的混色带。

### 4. 原作有方向明确的面明暗，当前灰面明暗主要依赖细凹痕和建筑投影

**实见：** 瀑布岩柱的朝上面较亮、正立面居中、内侧凹口更暗，几块岩体之间遮挡关系清楚。普通岸崖也有宽块面上的明暗转折。当前酒吧近景大部分岩面是近似同一深灰，局部细痕提供的小范围明暗不足以分出厚度。餐厅左侧大黑三角沿岩面和草地连续，应视作建筑投影，不能误记为洞口。

**下一步：** 保持当前正常灯光与相机，必要的宽顶肩和侧面承担轮廓及真实遮挡；区域主图与法线承担不改变轮廓的宽岩层、分界和局部深浅关系。原作 Albedo 已证明底色里存在结构明暗，不能把这种表现一律排除为“假阴影”。同时不能画死餐厅建筑的投影去代替实时遮挡，也不调整光照消灭该投影。

### 5. 当前整屏的上下两条平行带仍强于“岩体—低地”的关系

**实见：** 当前正常中段镜头，上方灰岩与下方棕色土坎仍大段同向。新凹入口虽已打断部分土带，但建筑前路面、下坡入口和露土坎的色彩接近，容易连成一条黄褐色装饰带。原作 20 秒图在岩脚留出宽窄不同的低草地，再进入沙湾；桥头裸土通路是清楚的行走区域，周边草地与岸坡承担各自用途。

**下一步：** 保持已有楼板位置与基础承托，先明确岩脚低地、建筑共同院地、实际步行路和海滩各自占地。只在实际磨出的路和露出的坡面保留土色；不要为了表示道路而把所有建筑正面连成等宽、等色的一圈。道路具体改法需与专项道路复核合并判断。

## 建议下一次实作范围与判断方式

先集中处理酒吧—餐厅之间这段真实可见岩面。若单色轮廓仍不足，再调整为一个宽凸主体、一个较低短肩、一个侧向收回的面，三者宽度和高度不相同；已有成立的大高差不必再次全量重建。脚部保留真实厚度及原有高台承托。同步为该段建立针对冠脚、侧转面和低肩的区域底色/法线组织，不能继续完全依赖同一 3.2 米重复图。此处已能看清效果，暂不同时扩展到整岸和所有建筑。

在相同相机、光照下分开看单色和区域材质结果：单色负责判断大轮廓、厚度与接地；材质版本负责判断宽岩层及少量分界能否在正常游戏距离保持可读。不能要求所有内部岩层在单色下都成立，也不能用“用了几何”或“更有高差”替代最终画面判断。

此为本次图像观察与建议，不是新的制作成果，也不构成用户视觉认可。
