## 实施关系

- 礼拜堂、礼拜堂侧木屋最低阶、医院、医院侧木屋最低阶、旅行社由一条有实际路床的上层 frontage 通路连接。旧医院断崖弯与礼拜堂短陡坡退出，不保留其道路颜色。
- 旅行社至学校经旅行社 Z42 一侧和 X28.65 后侧绕行，再通过 X30 附近内陆鞍部接学校。避免将 X22..25、Z49..55 的整条低谷抬成连续高墙。
- 四处公共院地依真实最低台阶底面设计，提案高度分别为礼拜堂 4.22、医院 4.53、旅行社 4.35、学校 4.50。两处木屋是最低一级台阶的落脚地，不能误用木屋地板高度。
- 平整路幅、相邻路口与外侧坡肩必须共同设计。路线半宽之外的 `shoulder_width` 仅是紧邻路缘的过渡，不能用它作为全部填方边界，否则会在遮罩边上制造新墙。

## 离线核对与仍需解决的形体

上层 frontage 平面长度约 32.59m，控制段最大纵坡约 6.53°；学校绕行约 30.06m，最大控制段纵坡约 3.22°。这些只描述提案中心线，不能代替最终网格检验。

当前提案路缘存在两处大填方热点：医院接近段约 `(21.39,26.21)` 从现有 H1.30 升到 H4.42，差约 3.12m；学校转回门前段约 `(21.59,56.24)` 从 H1.18 升到 H4.38，差约 3.20m。这两处必须用宽的实体山肩/院地承托、转回坡脚来解决，不能只沿窄路线抬高，也不能称为“仅适度局部填方”。医院可在不侵入真实基础的前提下微调接近路线向内陆，但临近基础 X22.974 和路幅宽度约束，仍需要真正的承托形体。学校北侧转回门前同样不能只移动中心线就消除全部支撑需求。

真实基础/楼板保护优先，树、桶、箱、花箱与岸石应整组移动后重新接地。JSON 中的 `relocation_candidates` 只是包围盒距离候选，不是自动移动名单。花箱边带属于同一花箱，不能重复独立移动。树冠/树干、桶盖/桶箍、箱体/箱框必须保持组关系。

## 主代理提出的两条上下层连接

北连接：`(13.2,18.8,1.2) → (17,19.1,1.8) → (20.2,20.4,2.8) → (23.45,23.15,4.18)`。

南连接：`(12.3,44.5,1.3) → (16.7,44.3,2.1) → (19.5,42.7,3.1) → (21.7,39.2,4.14)`。

按全部 Town/Hut 实际楼板世界包围盒，每约 0.025m 采样中心线，两条均无相交。北连接距餐厅 `Town_Floor.004` 最近 1.220m；南连接距酒吧 `Town_Floor.002` 最近 1.362m，距 `Town_Floor.001` 最近 1.939m。若路面半宽 0.70m，最小路幅余量约 0.52m 与 0.66m。该结论不包含整个宽坡肩/切填方体积，不能用来授权覆盖基础。

北连接末段在达到精确端点前就进入上层路幅的相邻范围，而两条独立线性插值高程尚不完全相同。需要把接近端点的一整块路口按共同高程重建，避免两个独立雕刻遮罩形成台阶或交叉隆包。南连接与上层 `(21.7,39.2,4.14)` 接点较直接，同样验证全路幅。
