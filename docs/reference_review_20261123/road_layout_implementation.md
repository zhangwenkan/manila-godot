## 坐标及证据级别

Blender 世界 `(x,y,z)` 转 Godot 世界为 `(x,z,-y)`。下列平面点统一写 **Godot `(x,z)`**；高度 `h` 是 Godot Y／Blender Z。换为 Blender 点即 `(x,-z,h)`。不要把历史 C25 脚本的离岸距离 `d` 当成世界 X：`p3(d,z,h)` 实际为 `(shore(z)+d,-z,h)`。

直接证据：

- 本轮 [foundations.json](../../demo/tropical_harbor_3d/captures/rock_path_sample_20261123/foundations.json) 和 [door_hut_contacts.json](../../demo/tropical_harbor_3d/captures/rock_path_sample_20261123/door_hut_contacts.json)：MCP 读取的楼板、台阶、住宅四角，均未在本子任务改变。
- [sections_before.json](../../demo/tropical_harbor_3d/captures/rock_path_sample_20261123/sections_before.json)、当前 GLB 顶点／三角形和备份 `before/assets/reference/shore_relief_height.json`：道路现状高度。台阶中心使用 GLB 三角重心插值，路线表使用 0.25 米缓存的双线性估算；实施仍以当前源网格射线为准。
- [当前最终图](../../demo/tropical_harbor_3d/captures/art_20261121_220358_404352/town_civic_street.png)：已实际查看。医院／礼拜堂前浅黄窄带、Sea Breeze 门前桌椅、酒吧前完整门廊与旁侧通海口可见。

推导证据：门位置由当前楼板四角反求建筑局部轴，再代入原建模门坐标；经过墙面加厚／门叶回缩的对象，须由主代理在当前源中确认最终门叶／门槛。不能把推导点精度当成现场测量精度。

**酒吧要特殊处理。** `Town_TavernPorchBoard` 系列底高约 `1.9650`、顶高 `2.0850`，木门廊外缘跨约 `x10.743–12.421,z38.497–43.089`。默认石阶部分位于门廊下／后，不能把接到该阶中心视作完成可见主入口。地面应接一个明确门廊入口或短踏步，保留其余木架外露与地面关系；不要把整个门廊底用土塞满。

`Town_Step.001` Rosie 底中心约 `(13.7946,1.4051,49.3321)`，下方地形 `1.1800`，另有约 `0.2251m` 差值。若本轮延伸到 `z49`，同样单独检查，不应复用 Sea Breeze 的高程。

## 先否定会穿坡或穿房的直线

原 `x24` 左右的连续上层路在 `z18–20` 与 `z32–34` 会穿越鞍坡：以缓存举例，`x24,z17` 约 `4.00`，`z18` 约 `2.94`；`x24,z31` 约 `4.28`，`z32` 约 `2.87`。仅改变材质会把短坎涂成路，不会获得可通行的地形。

简单把路后移到 `x28` 也不成立：

- `Hut_Floor.012` 位于 `(27.2651,4.5807,19)`，楼板 XZ 四角 `(25.63584,18.06839),(28.37465,17.48624),(28.89443,19.93161),(26.15562,20.51376)`；其前部台阶约 `x24.728–25.889,z18.828–20.004`。
- `Hut_Floor.010` 位于 `(24.7524,4.4903,36)`，楼板四角 `(23.12310,35.06839),(25.86191,34.48624),(26.38169,36.93161),(23.64288,37.51376)`；其前部台阶约 `x22.216–23.377,z35.828–37.004`。

因此本轮较小范围可采用**低街为主线，斜向支路通过坡谷连接上层门前小院**。若坚持一条连续等高上层主路，就要绕住宅背后至 `x30` 附近，并处理更多院地／植被；这已是更大的布局调整，不在以下小样段建议内。

## 路线控制点建议

所有“宽”均为**全宽**；折点应以连续曲线通过，不保留折线尖角。边界按使用空间形成宽窄，门前只接入口，不沿每面墙延长。表中现状高用于判断是否需要动几何，不是强制目标值。

## 实施边界

优先做一个可读路口、一个短支和真实阶底接触，再扩到下一段。保证楼板／地基、台阶底、门廊、桌椅、花箱与树脚各自核对。道路颜色区域只是表面用途；沙口、坡土与路仍分别处理。以上路线没有把所有建筑围黄边，也没有要求改镜头、灯光、航线或移动楼板。

若本轮只修改材质权重而没有完成坡带几何，就只记为门前局部表面重排，不能称上下道路已经贯通。实施后仍以当前源射线、侧向接触图与正常游戏机位确认，技术检查通过不等于视觉验收。
