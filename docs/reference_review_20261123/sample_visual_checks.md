## 对照方式与判断边界

新图先按上述三机位直接前后比较，不把额外近镜头作为唯一依据。先看轮廓、宽色面和道路目的地，再看接触和细纹；测试次数、三角面数量不计入视觉改善。

餐厅投在岩面和草地上的黑三角是已识别的建筑投影，保持当前灯光、相机和投影。不得为了消除它而变更灯光，也不在区域底色中画死该建筑阴影。

岩面内部的层理、局部深浅与浅凹凸可由区域底色和法线共同承担。单色检查仅检验大高差、厚度、冠脚与侧面，不要求所有内部岩层在无材质状态下仍可见。道路是否另做网格，应由真实厚度或台阶需要决定，而非因为旧黄带效果差就替换技术结构。
