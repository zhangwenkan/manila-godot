# 上台地道路—草肩—岩壁关系只读复核（2026-11-23）

用户对医院和贸易行的新否定覆盖前轮“连通改善、可收尾”的局部判断。前轮只核对断口、碎草与技术接地，未检查可行走表面的真实断面、路缘与坡折的对应关系，因此不能作为道路视觉合格依据。本报告不修改资产，不启动或连接 Blender。

**结论：上台地至少六处仍存在结构性问题。** 主要矛盾不是道路颜色不连续，而是道路、草和岩的二维占地没有遵循同一组路床、坡顶、坡脚。旅行社门前甚至有约64°的真实地形面被标成完整道路；医院蓝框的绿色直角条带覆盖的是59–73°的坡面。把这些区域进一步混色或清掉细草，不会建立正确的地形关系。

## 依据和测量边界

- 最终33图目录：`demo/tropical_harbor_3d/captures/art_20261123_220019_536387/`。33图缩略索引已实际查看；上台地主要复看 `town_market_chapel`、`town_civic_street`、`town_north_shops`、`terrace_cross_street`、`shore_grass_bank`、`town_landward` 和 `07_landward_connections` 的原图及局部裁切。
- 地形为本轮 `grade_before_after.npz` 的 `positions/triangles`，后续07只处理占地与草，不改变这些地形坐标。占地取最终 `road_contacts_20261123/land_data.npz`。读了实际运行的 `reference_environment.gd`、`landform_mass.gdshader` 及导出 town/coast/terrain GLB 的材质清单。
- 坐标一律为 **Godot X、Z，H为Y高度，单位米**。像素为原始1600×900图，左上角(0,0)。按记录的真实相机、48°视场，把像素射线与当前三角面求交；地面横断面也直接在三角面内插。
- “真实面坡度”是三角面相对水平的夹角，包含纵坡和横坡，不能都称作道路前进方向坡度。下文必要处另给按现有路线切线分解的局部纵/横坡。平滑顶点法线仅供对照，不是几何坡度。
- 射线只检测地形，不检测建筑遮挡。仅把可见地面像素当直接视觉证据；旅行社道路下端、学校正门周围部分被邻屋、招牌或吊机遮挡，完整路网判断由真实地形与占地图补充。**不据此声称学校台阶悬空，也不声称已完整看见被遮挡的路段。**
- 医院本轮降高仍只有17点、最大约0.0426米，不能写成已经削去明显短坎。

## 六处具体问题

### U1 医院右转处：草色直角条带铺在陡壁上

范围约 **X19.8–21.7，Z30.6–32.0**。`town_market_chapel.png` 像素约 **(1460,510)–(1540,665)**；证据 `terrain_logic_upper_audit/U1_clinic_grass_right_angle.png`。

图中院前窄草缘到右端突然转成宽而直的下垂草条，像一块绿色边框夹在岩墙与道路之间。它不是一个被建出的缓草肩：像素(1490,531)对应(X21.246,Z31.169,H3.822)，真实面坡61.43°，占地图却给草0.967、岩0.033；(1510,645)处坡59.21°，草0.911；中段(1492,600)坡72.96°，仍约草0.526/岩0.474。材质角色与面形不符，直角又把同一岩体的冠、侧面截成三条色带。

**结构改法：**把医院院地外缘、岩冠转向、下行路内缘作为同一个三维转角设计。选择做真实低缓草肩，或让岩体侧面完整转入路内侧的切坡；不能保留59°以上的绿墙再称草肩。草冠应在真实冠线内自然收拢，向下消失的位置服从坡形。道路外缘与内侧岩坡的宽度、回转半径同时确定。

### U2 医院院地与内弯：左端涂进岩面，转弯路床横坡未成形

范围约 **X21.1–23.3，Z27.3–31.0**。左侵入处见 `town_market_chapel.png` **(1290,470)–(1345,510)**；转弯见U1图上端。裁切 `terrain_logic_upper_audit/U2_clinic_rock_road_invasion.png`。

院前土路左侧越过坡顶后落到岩面，形成向下的浅土色舌头。像素(1330,497)对应(X21.299,Z27.976,H4.126)，面坡34.85°，占地为道路0.580/岩0.415。不是单纯贴图边沿噪声：同一院地多边形跨越了几何坡折。

转弯内部也不能靠加宽颜色修复：沿现有 `clinic_ramp`，(X21.8,Z30.5,H4.158)面坡52.95°；(X22.3,Z30.75,H4.000)面坡57.94°且道路权重1.0，按当前路线局部切线分解，纵坡约35.02°、横坡约55.12°。它是涂成道路的折皱坡面，不是稳定路床。此前保证中心颜色连续漏掉了道路整个宽度的断面。

**结构改法：**先确定医院入口平台，再建内弯完整横断面；平缓路面应有明确宽度，内侧接真实切坡/岩肩，外侧自然回到岩冠或承托。院地左端先退回实际坡顶；若需要更宽院地，应同步建实体平台与承托。建筑接地点与道路自由区域需区别，不能用宽泛投影锁住路床后仅靠占地图扩宽。

### U3 礼拜堂—旁侧木屋：连接形状像上坡，实际有凸坎、凹槽和陡横坡

范围约 **X22.3–24.6，Z15.7–20.0**。`town_market_chapel.png` 像素约 **(870,418)–(1020,468)**；`terrain_logic_upper_audit/U3_chapel_access.png`。右侧木屋入口接入后，路面与周围绿色立面仍呈V形夹口，路缘在陡面上突然下垂。

按现有路线取样：从礼拜堂向木屋方向，(22.3,15.3)H4.011，(22.7,16.5)反升至H4.214，再到(23.9,17.6)降为H3.259，随后(23.8,19.1)又升至H3.623。这里不是单调、可理解的上坡路床。尤其(22.9,16.9)面坡60.23°、道路1.0；沿现有路线分解纵坡约50.83°、横坡约51.22°。像素(974,436)对应的木屋接入边面坡48.59°、道路0.979；旁边(1003,448)是69.05°面却草0.901。

**结构改法：**把礼拜堂入口、木屋楼梯落脚和下层来路放进一条明确的缓坡/分段台阶体系，先连通高程和平台，再安排材质边界。木屋台阶下应有真实水平落脚点；两条来路合并为一处可读的交会面，剩余陡面应成为完整的土/岩切坡。北侧(X约22–23,Z约10)圆头支路目前终止于草地，去向也应在共同路网设计中明确，不能继续当装饰线条保留。

### U4 旅行社门前：短道路直接翻下台地断面，未接入有承托的通路

范围约 **X20.5–22.6，Z46.0–47.0**。`terrace_cross_street.png` 像素约 **(887,444)–(933,493)**；`town_north_shops.png` 约 **(682,382)–(717,424)**。证据 `U4_travel_entry.png`、`U6_upper_connectivity.png`。

门前短土路从门槛向海侧直落，颜色看似一条入口，但地形是上下两级陡折。(X22.0,Z46.5)H4.003，真实坡64.53°，道路1.0，沿路线纵坡约64.05°；往海侧到X21.75为H3.618，再到X21.0为H3.476。更外侧X20.25已降到H2.678、X20.0为H1.638。土路在上层断面结束，下面是岩壁与低层草地。

独立像素复测(914,456)/(917,475)/(914,488)均落在62–63°真实面上，道路权重1。部分下端被Rosie招牌遮挡，不能只凭单张正面图声称完整断头形状；但最终占地图只保留这条朝-X短入口，GLB中也没有另一个独立路径材质替代它，不能视为已接通。

**结构改法：**旅行社入口先形成退在真实坡顶后的平台，然后沿台地转向接入侧向公共路，或明确设计有平台与承托的阶梯下行。不要继续把一条短路径从门前笔直画过断崖。先选通路去向，才有依据决定哪一段岩冠退后、哪一段保留岩体。

### U5 学校正面：入口前是草坡，没有进入同一套道路/院地组织

范围约 **X22.0–24.0，Z58.4–60.3**。`shore_grass_bank.png` 像素约 **(1080,262)–(1210,310)**；`terrain_logic_upper_audit/U5_school_front.png`。学校前看到的是门槛—窄草区—灰岩面的顺序，没有与其他公共建筑一致的入口院地和来路。

Z59.25横断面中，X22.0–23.5道路权重全部0；X23.2,Z59.2,H4.207处草1.0、真实坡32.22°，X22.0处H3.647、坡33.97°，再向外是约66°的完整岩面。最终16条路定义中没有学校入口，实际town/coast GLB也无额外路径材质。因此它不是仅被草簇遮住的已建道路。正门部分被Sari与吊机遮挡，报告不推断楼梯是否悬空；缺少道路占地和路床是可复核事实。

**结构改法：**学校门前应有一个真实可停留的院地，与旅行社方向或学校侧后方的上层公共路连接。院地和侧向通路先服从既有门槛高程，再让坡冠绕开它，而不是直接向海在灰墙上再画一条入口。树、石和旗杆应在这套空间确定后安排。

### U6 学校前长岩面：岩材质基本正确，但冠线与体量仍是连续高墙

范围约 **X20.5–23.0，Z55.7–62.0**。`shore_grass_bank.png` 约 **(1060,292)–(1360,425)**，`town_north_shops`学校下方；同U5裁切可见下段。

这里与医院绿墙不同：大部分陡面确实为岩权重约1，不能归因为路/草贴图误染。Z59.25的X21.0–21.5约66–67°，H1.91→3.05；上层平台高度约H4.29。沿Z55.7–62.0，H4.0这一上缘等高线仅在X22.68–22.93间变化约0.25米，形成约6.3米近直的高冠线。低处坡脚有变化，不能把整片说成顶脚完全平行，但在当前正面镜头仍读成一堵连续灰墙；增加细纹不能改变这一轮廓。

**结构改法：**按学校院地与侧向通路先确定必要平台，再把剩余岩体组织成少量不同方向、不同进深的真实岩肩与凹口。顶部应有明确的草根层/薄土覆盖，岩面转折、坡脚承托与出入口共同形成非平行轮廓；不要使用周期波纹或重复小板岩去遮挡整条冠线。

## 共因与后续实施顺序

运行shader先读取网格颜色，但在图集覆盖内会由G23占地图替换；后续只做草缘扰动和领先权重锐化，不会把陡面上的道路重新变成岩/土。旧全域绘路曾用平滑顶点法线过滤，而平滑法线会平均掉短坎：旅行社真实64.5°面上的`map_normal_up`可达约0.81；道路依然保留。最近三框修复又移除了局部坡度过滤，扩大路径权重后没有得到匹配的路床。两者都解释了“颜色有路、实际还是坡墙”的观感。

后续应先画出上层公共来路与各建筑真实入口的关系，建立入口平台、整条路宽的纵/横断面，再确定道路外侧坡顶/坡脚。以这些三维界线生成路、草、土、岩的占地；只在真实交界处做小尺度侵入。先检查无材质轮廓和断面，再上材质，最后检查植被/石头占路。当前没有实施这些改法，也没有任何视觉合格结论。
