## 下一轮修船厂样区：具体设计与验证顺序

1. **先定一条可读的工作路线。** 在已认可 B 厂房＋A 石坞轮廓内选“岸上入口—厂门踏步—坞侧工作面—海侧承重外缘”，用现有尺度核对干地搬运与临水检修各走哪里。保留坞槽深度、滑道与船净空；不用低矮鱼摊的台面比例替代厚重石坞。
2. **把三种地面职责分开。** 岸侧连续地面负责通路；门前／检修边少量踏步负责高差；海侧厚挡墙和承重石边负责重量。顶部铺地先读作工作面，再显接缝；不把所有地板块、外缘石和门台都处理成同等强度的小凸块。城镇参考支持连接层级，不提供可直接复制的石块尺寸。
3. **保留深灰蓝与明显锈蚀，组织视线层级。** 用大面旧漆、主要搭接／泛水、压型沟、小紧固件四层先后可读；锈蚀仍形成显著块面，再沿接水、折边和连接处出现局部细节。避免每条沟、每个螺钉都同样黑亮。鱼摊的“先识别用途，再补局部纹理”可以迁移，红白棚色、鱼皮表面和纤细支架不能移植为工业材料配方。
4. **用一个连接部位和少量道具证明功能。** 只选厂门旁“檐口／立柱—墙脚—工作台—地面”的现有部件，检查板、梁、托架、绳的真实连接和物品操作空间。复用已认可桥的完整构件、UV 与材质；不靠更换全港颜色来消除塑料感，也不扩建新鱼摊或其他建筑。
5. **分阶段验证原因。** 几何／UV／Blender 材质仍只能经本项目独立 Blender MCP。先锁当前白天与相机，比较结构改动；再比较深灰蓝旧漆与锈层的分区；有确定问题才单独改填充／投影。唯一主场景分别检查近船正常构图、较低船侧、厂门和侧背面、岸端至海侧高差。固定屏幕尺寸和曝光，记录暗部材质、连通路、净空、投影，不把运行检查等同视觉认可。
