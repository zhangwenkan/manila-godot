### 叶簇、材料与颜色各能证明多少

**V：** 从总览到近景，轮廓先读为几个不等大的团簇，再读出交叠尖叶；外缘有少数突出叶尖，内部保留深绿暗部。25 秒可见浅绿、黄绿、深绿叶面，橙果是稀疏点色；部分颜色明暗来自叶面朝向与遮挡，不能全称为随机材质变体。果实并非均匀悬在外球面：局部埋入、萼部及细枝帮助建立连接。

**U：** Blender 材质属性面板及 Base Color、Metallic、Roughness、Normal 等栏目可辨；没有可读完整参数、图像列表或节点连接。面板出现 Normal 字样不等于使用法线贴图。

**未证实：** 叶片纹理是否存在、图集/UV 布局、alpha 模式、法线贴图、法线编辑、双面光照、粗糙度范围、顶点色、材质数和引擎 shader；Unity 使用来自作者描述与 “in game” 标签，样帧未显示足以审计渲染设置的 Unity 编辑器。不能声称“无贴图全靠几何”，也不能把表面折光直接归因为 normal map。

**I，可迁移：** 把大簇轮廓、少量朝向组、薄叶的明暗折面、颜色角色和有支点的附属物分别设计。橙果并非岸线灌木的必需品；本项目只需低矮稀疏的植被组时，不应复制果园式密度。微动适合低幅、低数量，但是否加入由后续授权和使用场景决定。

### 46.8 秒：对岸线融合最直接的补充

**V：** 左前建筑是较深的竖向木墙大面，浅色檐边/边框负责轮廓；门前有单独平台。中央圆形建筑的石砌分缝沿曲面转折，入口略凹，底部连续台阶/基座有明确承重角色。右侧小屋有大块红顶、较浅墙面与深色细框，墙脚仍可见。后方也可见两侧立面不同明暗的房屋、近水建筑和船。

道路是连续的裸土地带，宽窄变化后分叉到门口；绿地在路边形成不规则但可读的边界。草、花和较大灌木分级，许多区域仍有地面空隙。多数门口、台阶和墙脚没有被一圈等高灌木封住。图中有硬檐线、直墙角与深投影，不能据“自然融合”要求统一圆角或淡化所有边缘。

**未证实：** 46.8 秒能看到连续路径的外观，但不能证明它是否使用 mesh、terrain splat、decal 或 shader blend；可见石缝也不证明每块石头独立建模。这一帧不提供干湿沙/基础的精确垂向剖面；后方房屋的侧面不等于完整背面遍历。

## 对 B 工业厂房 + A 石坞的可迁移规则

以下为 I（设计建议），未制作，且不授权扩建其他建筑：

1. **先保留工作路径。** 从门口、石阶到坞底形成连续可读的作业面；让植被退到墙脚转角、低使用率凹处或沙地的零散边缘。不能用一圈草掩盖所有铺地间隙、悬空基座和岸端高差。
2. **承重外缘先成立，过渡物随后。** 石坞需要看得见的底部承托、台阶或入沙关系；草和小石只补局部过渡。46.8 秒中央石构的连续基座与断续地表植被角色不同，不能把两者都切成等节奏小块。
3. **保留深灰蓝和锈层的材质角色。** 本轮绿植证据不支持把厂房再刷浅。暖光下的红顶、浅墙也不是本项目的通用色板。优先区分压型板、折边、石质基座、裸土路径与叶簇的形体/反射角色。
4. **植被按组设计，不按边长等距摆放。** 少量不同高度/宽度/朝向的低叶簇，配稀疏草花与留白；把“近看有折面和层次、远看仍是一团”当作可测目标。不得把可见颜色差异直接转换成满场随机色。
5. **连接与遮挡要可信。** 借鉴果实返工的判断方式：装饰物必须有落点或固定关系；在正常相机中核对叶簇遮挡比例、台阶净空、门前通路，而非只在 Blender 特写里漂亮。
6. **分阶段确认。** 先以本项目固定白天、同机位比较地面主次与高差，再看稀疏植被是否改善边缘。任何后续网格/UV/贴图修改仍只通过独立 Blender MCP，进引擎后同时看正常航行视角与真正低角度。
