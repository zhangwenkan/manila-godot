# 材质、明暗、投影与细节频率复核 · 2026-11-13

原作允许清楚的硬轮廓、较深的投影和规则接缝。画面统一主要依赖大面、骨架、接缝与表面细节的分工，不能概括为“所有东西都软、都浅、都哑”。现有修船厂应保留用户指定的深灰蓝、旧漆和明显锈蚀，优先调整各尺度信息的反差与落地关系。

本轮仅分析已有本地图片和已核实的研究记录；没有操作应用、重新拍摄、运行游戏、建模、改变材质/光照，或导入原作资产。B 工业厂房 + A 石坞、维修船、石阶的基本轮廓已获认可；当前保存并截图的是浅灰蓝试版，本文不把它当最终颜色目标。

## 已核实机制：沿用已有证据，不再由图片猜参数

依据 [2026-11-12 风格统一复核](../harbor-style-integration-study.md)第 2—4 节：

- 小屋、码头及选定石材使用 `HDRP/Lit`，已绑定 Albedo 与 Normal；部分梁板角色、接缝和板内明暗在仅 Albedo 的取证中仍可见。这不证明每一笔由手绘完成，也不说明正常游戏没有几何、光照或描边贡献。
- `BeachInkOutline` 有选择地处理深度/法线边缘，并以有色乘法合成；`SoftInk` 降低线强度，**不是图像模糊**。不能把参考中的浅一些的线直接翻译为模糊整栋建筑。粗糙度曾被原作用于描边标记，也不代表本项目应靠全场增大 roughness 实现同样功能。
- 保存的 `BeachVolumeProfile` 使用 Neutral；SSAO 组件 inactive，ContactShadows 的 enable 为 false。`DayNight` 有运行时 Volume 配置路径，因此静态值不能证明所选四帧的 AO/接触阴影一定开或关。
- 保存设置与材质表并未给出某一视频帧的完整有效照明状态。Unity 与 Godot 的色调映射、光能、AO 参数不可按名称或数值直接搬用。

## 本项目对照：先修主次，不用浅色化解释统一

**BASE 的有效关系。** 深木骨架包住较浅板面，码头上表面和承托/桩有明暗与体量差别。船体大曲面、舷边和内部横向部件先可读，木纹随后出现。桥在水域里的投影相当明确，因此“投影强所以不搭”不足以解释修船厂；现有船桥可与清楚的深投影共存。

**YARD 实际机位。** 浅色石台与沙地接近，但正面层层压顶、侧壁砖列和顶面铺装仍连续显露。前沿、立面缝与顶面缝重复排列，石台成为一组边界很完整的块体。这个问题在颜色变浅后仍存在，与已有几何审计“铺地、挡墙、压顶使用近似块体语言”的结论相符。截图本身不能量出缝宽，也不能证明该外观由 AO 单独造成。

**YARD_ROOF 局部。** 压型沟每隔很短距离就产生一组亮暗，檐下百叶又是一组深横线；天窗外框、窗格、板搭接、螺钉和檐口同时很醒目。下缘锈色在许多连续波谷附近重复为相近的小楔形，板侧又有较长锈带。这些信息证明铁皮已有压型、紧固与锈蚀表达；仍待改善的是大小节奏及重复形状，而非再均匀追加“旧化噪声”。本轮没有从图片判定它们来自几何、Albedo 或 Normal 的比例。

**原作屋顶提供的是组织办法。** 它的板缝也规则且较清楚；但宽色带、屋脊和板面的大分区足以压住细节。工业厂房可以采用自己的搭接和锈蚀构造，不必复制木屋色带或减少到木屋的板材数量。原作未提供这座工业铁皮建筑的同类实物配方。

## 保留深灰蓝锈铁的整合建议

以下是项目设计建议，尚未实施或得到用户视觉验收，也不是从原作提取的参数。

| 层次 | 应首先读到什么 | 对现有修船厂的处理目标 |
| --- | --- | --- |
| 远一些的实际航行机位 | 厂房屋面/墙面的深灰蓝大体量、石坞工作面、维修船与出入口 | 恢复用户指定的深色方向后保留连续旧漆面；锈蚀形成有因由的大小分区，不将深色区域打碎成满面高反差小点。石面作为较安静的承托区，而非另一个等强细缝图案。 |
| 正常建筑观察 | 屋脊、檐口、山墙、门窗框、较大板搭接和主要锈蚀区 | 主要构件的分区反差大于密集压型沟。压型依然清楚、有硬度，但不要求每条沟在所有朝向都同时呈强亮线/黑线。保留深檐下和受力连接的阴影，暗部仍能辨别材质与次要结构。 |
| 结构近景 | 紧固件、旧漆边、积水/接缝锈迹、压型细节和局部磨损 | 螺钉和小锈点在靠近时成立；锈边不沿所有波谷重复同一轮廓。大锈色块不必同步成为大幅凸起；残漆、锈层、裸露金属各自保留合理的反射差别。 |
| 与船桥相邻 | 共享环境、相近的细节可读距离，木/铁/石仍各有材料角色 | 用已有旧木、绳索、灰石和少量赭锈形成相邻色彩关系；不将铁改成木色，也不强迫各材料使用相同纹理频率或粗糙度。已有深木框架和深铁框架可以对应“骨架角色”，板材表面仍各自成立。 |

深色能否成立，宜检查“旧漆的大面是否完整、亮面和暗面的方向是否清楚、暗面是否保有层次”，不要先把整场曝光抬高。深灰蓝旧漆与明亮沙/海存在反差是合理的；必须解决的是反差落在什么位置，以及石坞怎样接地。

## 后续受控验证方式

1. 使用唯一主场景的现有固定白天，保留相机、屏幕覆盖和灯光方向，先比较两级画面：实际航行机位是否先读到大形；结构近景是否才显出螺钉与浅凹凸。不要靠改变机位或缩小物体隐藏细节问题。
2. 先核对接缝几何、法线与纹理分工，再比较有问题的光影项。投影应交代檐口、百叶、工作台承托和墙脚；若暗缝、阴影、描边叠成一道连续黑框，分项检查来源，保留有结构意义的部分。若需要试环境填充或 AO，仅改变一项并保留同镜头前后图，不预设复制原作数值。
3. 以右前沿石台—铺地—沙地—墙脚样区验证接地。顶面浅缝、承重外缘厚度和沙土接触应分工；不能用一圈均匀植物、统一加黑接触线或削弱所有投影遮住连接问题。
4. 在深色厂房、石坞、已有船桥同场景下确认主次后再推广。技术回归仅验证运行；用户对材质与整体协调的视觉判断仍需单独获得。

## 仍缺的证据

- 四个视频时刻的运行时有效光源、Volume、曝光、阴影和水体状态未读取；软硬投影的具体因果仍未知。
- 截图颜色混合了本色、照明、后处理和显示编码；不能据它恢复材料本色或准确反射参数。
- 压缩参考板不足以判断细微 Normal、roughness 变化或时间上闪烁；本轮也未进行等尺度、等视角、同光照的原作/本项目材质实验。
- 当前实际机位样本为浅色试版。深灰蓝方案在同环境中的最终明暗平衡尚未落实，不能把本报告建议或已有 424 项技术检查当作完成与验收。
