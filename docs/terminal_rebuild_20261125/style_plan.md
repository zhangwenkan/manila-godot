# 终点重建：当前小镇材质与构件方案

2026-11-25。依据只有用户恢复的2D原图、当前`assets/reference/town.glb`材质清单及`town_civic_street.png`实拍。读取当前小镇三份制作记录和基础UV helper用于理解现状，没有查看旧终点3D资产、旧终点建模脚本或旧终点截图，没有执行历史制作代码，没有连接Blender或修改运行资产。

## 当前风格与视觉顺序

当前小镇采用柔和宽面、明确轮廓、蜂蜜色木构、暖灰米色墙和偏青蓝屋面。主要结构靠实际厚度、檐下阴影、凹入窗洞及楼层分隔读出来；正常机位不能依赖微小刻纹。新终点首先需要读出左高右低双塔、蓝色曲线屋面、中央低廊、左吊架和右墙铁锚，其次才是小旗、灯笼、绳结。

原图高塔的两级曲顶是识别重点：下层覆盖宽塔体，上层是收窄的小塔身与更高曲顶。不要把两级屋面压在同一平面上或只做一块凹曲薄片。曲顶需要同一连续底壳和明显木质前后山墙檐板，瓦片随真实曲面起伏，搭接保持克制。小塔屋顶及入口门罩沿用相同曲线语言。

建议比例起点（最终须服从真实场地）：左主塔屋身约宽3.0–3.4m、门高约2.0m，右塔约左塔宽的0.7–0.8；左塔含屋顶高度约现有双层酒吧的1.3倍，右塔约高塔0.65–0.75，低廊约0.42。先保留高低关系，不靠整体等比放大制造地标。建筑总宽和朝向由当前终点旧房与平台空间决定。

## 当前GLB实际使用的材质

| --- | --- | --- |

| 木台、踏步及工作台 | `Ref_TR20_deck` | 沿用当前板面，实际铺设方向统一，板端由实体厚度表现。 |
| 檐下承托、次级梁、屋底 | `Ref_TR20_beam` | 作为有限暗部，避免所有木框都深褐导致沉重写实感。 |
| 大面浅墙 | `Ref_TR20_ivory` | 直接使用现有暖灰米色；不改成纯白，也不铺满剥落点。 |
| 局部墙／内廊 | `Ref_TR20_plaster` | 当前略暖深于ivory，可少量区分背墙。 |

## 蓝瓦与表面

当前`Ref_TR20_blue`设计色为sRGB `#557B88`，材质贴图带约±宽缓颜色变化、不同区域粗糙度，运行法线强度0.26。新终点可在独立材质与独立底色图中把均色调到约`#3D6275`，作为当前蓝顶更深的起点；不要压至近黑。保留已验证的法线、粗糙度与宽缓变化组织，先用同一白天实拍判断。原图的深蓝是结构分区，不能用高对比斑驳或黑边描线代替。

复制材质时不要就地改当前town共享贴图。若要换底色图，应在已核实MCP中按原蓝图颜色比例生成独立新图、明确sRGB、打包并核对源图和磁盘，旧town材质与图像保持。避免在Blender中依赖复杂混色节点再假设glTF自动烘焙；最终导出的Principled Base Color应直接读取可导出的纹理。

瓦片宽度可取0.25–0.32m、坡向搭接排距0.35–0.45m，延续当前屋顶的尺度。前檐可见厚度约0.03–0.05m，底壳约0.08–0.10m，主檐木截面约0.12–0.18m。每片瓦仅很小色差和轻微轮廓错动，不逐片深刻裂痕。造型用曲面瓦和搭接阴影，表面只辅助。

## UV与连接

当前基础`remap_wood`按网格局部最长轴决定纹理方向：U是横向坐标×1.25，V是长向坐标×0.5；每对象有小UV偏移。木纹因此沿V。直梁应先在自身局部Z轴方向建长方体、完成UV，再旋转到端点；不先烘成世界坐标后按包围盒选错长轴。屋顶弯檐板宜用累计弧长作为V，截面宽度作为U；屋顶瓦用坡向弧长与沿屋脊方向建立UV，不把同一平面投射直接拉伸过曲面。

当前木、墙、石法线强度约0.48，屋面／油漆为0.26。这里的数值是现有资源事实，不是强度必须不断加大的目标。正常机位下主梁倒角约1–2cm、次级框约0.5–1cm，尽量沿用当前小镇0.008–0.025m的边缘尺度。玻璃／门应退入墙面约0.1m，窗框略突出，真实洞口厚度约0.18–0.22m；不要用一块玻璃薄片盖在完整外墙前。

吊货架使用主水平臂、斜撑和墙上锚固组成三角支撑；吊绳从滑轮落到吊钩和实际木料兜索，吊木靠近台上作业区，别悬在船头上。右墙锚饰用粗而有收分的实体轮廓，圆环与横杆分清；保持与墙面的小间隙产生阴影，避免雕刻平面贴图。基础仅处理建筑自身接岸，不重新调整整片地形。

## 实拍判断

先看同屏船、当前木平台及双塔：木色不能突然变灰旧，墙不能过白，蓝顶不应黑成剪影。正面单体确认高低塔、两级曲顶和门罩轮廓；参考角度确认屋面有体积、廊道有深度；背面确认围护和支撑完整。若正常距离只看到许多细线，应减少杂纹、强化大面与连接，不加更多磨损。技术检查与视觉判断分别记录。
