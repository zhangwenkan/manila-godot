## 本轮制作决定

1. 用 Blender MCP 制作真实连续岸侧土台，按当前 -60° 实际变换衔接现有沙地；厂后较高地面逐渐落向岸侧通路，海侧维修槽、船道与入水木梯保持清楚。
2. 重排石坞外侧承重墙的石材分段与铺地：承重石材更大、分层和错缝不齐整复制；铺地读作连续作业面，降低原88块小方格的重复感。硬棱、石坞重量及工作平台高度保留。
3. 岸侧入口以宽踏步、落地平台及连陆通路形成明确出入关系。泥土覆盖和植物只放在较少使用的局部，不沿底座均匀摆一圈。
4. 地形先通过正常游戏机位检查，再处理旧铁皮重复锈纹和大色块。固定白天、相机、水面参数；不以节疤、细纹或大量采样检查替代整体改善。

参考依据：已有多视频复核中的桥端裸土—草地—河岸关系、城镇临水挡边与入口通路。只研究制作方法，不导入原作资源。旧货仓不是质量标准。
