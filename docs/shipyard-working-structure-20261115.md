# 修船厂屋面构件与滑道层次 · 2026-11-15

当前资产已继续进行 [立面与侧后接岸整理](shipyard-facade-ground-20261116.md)，保留本页最终屋面与滑道结果；本页49网格为前轮快照。

用户“好的继续”后，继续改善同一修船厂。前轮石墙与岸坡结果保留，本轮处理正常游戏机位可见的厚天窗框、过于平滑的通风罩和颜色接近船体的维修滑道。

制作决定：保持B厂房的整体轮廓、深灰蓝重锈屋面和现有开窗位置，减轻天窗边框与分格条的体积；将通风罩帽改为有明确折边和搭接的薄金属板。滑道木面改为较灰的旧木色，轨木/船托更深，保留维修船本身的暖木色和有效纹理。构造/大色块优先，不以细纹、螺钉或磨损数量作为主要进度。

所有网格、UV、材质与贴图操作均经本项目独立Blender MCP（首段PID6312，后段独立重开为PID39452，分别核对9878端口和本项目源文件）；外部仅负责通信、只读分析、对照拼图和验证。备份为 `demo/tropical_harbor_3d/captures/shipyard_working_structure_20261115/before/`，包含前轮最终45网格石墙/岸坡结果。

## 本轮已保存的修改

- 将原10片曲面通风罩帽、2条旧滴水边和2条厚端挡条归档，换成5片有搭接的6毫米折板与2片贴合顶帽轮廓的薄端板。保留百叶、立柱、通风罩原体量及排气管；主体屋坡、深灰蓝与重锈纹理保留。
- 侧背面复看发现新平顶帽受光后过浅，最终为它单独建立 `W15_WeatheredCapPaint` 与 `W15_CapPaint_albedo.png`：粗糙度0.88、金属度0、Specular IOR Level 0.2，原图集副本的sRGB分量乘以0.66/0.76/0.86。罩帽在侧背面保持较深蓝灰色，主屋面图集与锈区不变；中间偏浅版不作为最终交付。
- 天窗8件边框保持原开口位置，横框宽度减至56%、侧框宽度减至62%、局部高度减至65%，同时按屋面降低。原6根圆截面分格杆换成26毫米宽、24毫米高的T形压条，底部贴近玻璃；保留原泛水搭接。
- 两处天窗各保留三列两排分格，增加克制的逐格明暗和边缘积尘，粗糙度与积尘对应。当前是带粗糙度图的不透明介电玻璃近似，不宣称已制作真实透射或内部空间。
- 29块滑道横木、4块临水木梯踏板使用较灰的旧木色；2根长轨木、6件船托、3件龙骨垫和2根梯梁使用更深的承重木色。原图集、有效UV、顺纹法线和粗糙度保留；维修船本体、吊架与工作台未统一改色。
- 前轮60件石墙、16块大铺地、侧阶、岸坡、植物与木料堆承托保留。主镜头、航线、水体、日光、原A/B、终点与航行船桥不变。
