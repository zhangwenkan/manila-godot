## 当前改动

- 次级檐条、横条、窗框等木作截面收至原来的约68%，承重角柱保持；门罩屋面起伏收至82%。主要与次级木框分别改为较灰的风化木色，压低浓褐色包边感。
- 屋顶仍为深海军蓝，进一步收低蓝色彩度，保留原瓦片、法线和粗糙度。暖灰墙、双塔曲檐、吊货、旗布、左长桥与三泊位布局保留。
- 两塔下增加连续石质承托，前部延至正常机位可见的位置；后侧约1.84m宽的岸径接向现有沙地。前方装卸木甲板和左桥仍保留。新承托深入水下，不是贴在平台边上的颜色条。
- 现有沙地表面增加连接终点与修船厂作业区的压实通路、较宽湿砂带与大片低植被地表底色；原来的浅黄沙地不再覆盖整个陆面。减弱海床本色额外的强青化，保留现有水面 shader。未改地形网格、高度采样、日光、曝光或AO。
